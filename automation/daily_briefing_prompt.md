# GBRC 매일 브리핑 자동화 프롬프트

작업 디렉터리는 `C:\Users\geunt\OneDrive\Desktop\주식`이다.

이 작업은 Path-B다. 다음 순서를 빠짐없이 수행한다.

1. `AGENTS.md`와 `docs/etf_system.md`를 전부 읽는다.
2. `py gbrc.py briefing`을 실행한다.
3. 출력된 run manifest를 읽고 `status`, 두 펀드의 `as_of_date`, `quality_status`, `performance_status`를 확인한다.
4. `status`가 `success`가 아니면 최신 자료인 것처럼 해석하지 않는다. 첫 줄에 `데이터 지연/부분 실패`를 표시하고 실패 원인과 재확인할 항목만 보고한다.
5. `git status --short data/normalized/etf_holdings/`에 보이는 새 검증 스냅샷만 경로를 지정해 커밋한다: `git add <경로…>` → `git commit -m "data: YYYY-MM-DD TIME·KoAct 스냅샷 (codex)" -- <경로…>`. 새 파일이 없거나 커밋이 실패하면 브리핑은 그대로 진행하고 그 사실만 한 줄로 적는다.
6. 성공이면 생성된 `data/derived/briefings/YYYY-MM-DD.md`를 읽고 아래 순서로 한국어 브리핑을 작성한다.

출력 순서:

- 오늘의 한 문장 결론
- 데이터 상태와 두 펀드 `as_of_date`. manifest `backfill`에 `stored`가 있으면 채운 건너뛴 날을 한 줄로 적는다
- 내 7종목 점검: `## 핵심 결론`의 `[내 7종목 점검]` 표, 대기 종목, 재조정 미리보기, 7종목 모델 줄을 그대로 옮긴다. manifest `desk_digest_status`가 `generated`가 아니면 그 사실만 한 줄로 적는다
- 두 펀드 공통 흐름: `## 핵심 결론`의 `[두 펀드 실매매 합의]`에 있는 D-5·D-20 공통 실매수·공통 실매도, 공통 섹터 방향
- 두 펀드 디버전스: 실매매 방향이 엇갈린 종목, 한 펀드만 크게 실매매한 종목
- TIME 미국 상장 Top 10 관찰군: 순위, 각 종목 실매매 D-5·D-20, Top 10 진입·이탈
- TIME: 현금 방향, 주요 섹터 변화, 실매수·실매도 상위, 신규·편출
- KoAct: 한 줄 — 현금 방향과 가장 큰 실매수·실매도 1~2개. 나머지는 보고서 파일로 안내
- 비중이 크게 움직인 종목은 `실매매(수량)` 열로 `실매수`, `실매도`, `가격효과`를 구분해 표시
- 가격 성과: D-5·D-20 두 펀드 수익률과 우위를 한 줄로. D-1·D-3 표는 보고서 파일로 안내
- 오늘 확인할 종목: `공통 실매수 관찰군`, `단독 실매수 관찰군`, `공통 실매도 관찰군`, `뉴스·실적 확인 필요`
- 생성된 전체 브리핑 파일 경로와 run manifest 경로
- Gate C 자기검증

`직전 변화 복기`와 전 보유종목 표는 채팅에 싣지 않고 보고서 파일 경로로 안내한다.

주의사항:

- 비중 변화만으로 매매를 말하지 않는다. 매매는 `실매매(수량)` 판정(설정·환매 공통 배율과 주식분할을 뺀 선별 수량 변화 ±5%)으로만 말한다. 비중이 늘어도 `가격효과`면 운용사가 산 것이 아니다.
- 실매매도 PDF 공개가 매매보다 약 2거래일 늦어 자동 매매 신호가 아니다. 확신 변화 신호로 읽는다.
- 실매매 판정이 `N/A`(지수선물 등 수량 없음)이면 판단 유보로 남긴다.
- 현금은 각 펀드 내부의 D-1/D-3/D-5/D-20 방향과 지속성을 우선 본다. TIME의 선물 보유가 있으면 현금만으로 방어 전환을 단정하지 않는다.
- 옵션·PER·개별 목표가를 Path-B에 섞지 않는다.
- 가격 또는 원천 데이터가 없으면 `N/A`를 유지한다.
- 전체 보유종목 표는 생성 파일에 모두 있어야 한다. 응답에서 표를 직접 제시할 경우에도 일부만 샘플링하지 않는다.
- 실제 매수·매도 검토 전에는 별도 Path-N 뉴스 확인과, 실적 이벤트가 있으면 Path-E를 권고한다.
- 목표비중·주문 수량·주문표는 브리핑에서 계산하지 않는다. 주문 계산은 야간 데스크(`docs/desk_system.md`)만 한다. `[내 7종목 점검]`은 종목·순위·운용사 실매매만 보여 준다. 운용사 매도를 이유로 7종목 규칙보다 먼저 팔라고 권하지 않는다.
- 현금·선물·한국·일본·홍콩 보유분은 펀드 전체 흐름을 해석하는 맥락에 포함한다. 사용자가 실제로 확인할 종목 관찰군은 미국 상장 종목으로 한정한다.
