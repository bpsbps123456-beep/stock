## 문서가 모호해 정한 해석
| 항목 | 해석 |
|---|---|
| MOCK 강세론 조롱 '12' | 문서에 단어가 11개만 있다. 11개를 썼다 |
| TILT 국내 | 10개 + 'SKHY는 국내로 센다' → 11개 |
| 종목 별칭 | 'topic 부록 A·B' 파일을 찾지 못했다. lexicon §6 별칭만 썼다. '델'은 대문자 DELL만, MU도 대문자만(소문자 영단어와 겹침) |
| 2음절 낱말 경계 | 원문에서 바로 앞 글자가 한글 음절이 아니어야 한다(왼쪽만). 오른쪽은 조사가 붙으므로 보지 않는다. 그래서 '부분익절'은 세지 않는다 |
| 공백 지우기 | 띄어쓰기·탭만 지운다. 줄바꿈은 문장 경계라 남긴다(줄을 넘는 매칭 막기) |
| 영문 티커 | 대소문자 무시, 앞뒤에 영문자가 붙으면 세지 않는다. 숫자로 끝나거나 시작하는 표현(2배, 현금 100, 10년 뒤)은 숫자가 이어지면 세지 않는다 |
| 가장 긴 표현 먼저 | 경계를 통과한 후보끼리 길이순으로 자리를 잡고, 그 뒤 제외 문맥을 건다. 제외된 표현은 자리를 내놓지 않는다(덜 세는 쪽) |
| 제외 문맥 | lexicon 관례대로 '같은 단위에 있으면'으로 보고 공백 지운 부분 문자열로 찾는다. 같은 단어면 다른 셈(MOCK의 한강·설거지 등)에도 건다. '다리'(기다리)·'신용도'(신용+도) 같은 부작용은 덜 세는 쪽이라 그대로 뒀다 |
| 던졌의 주어 | '외인·외국인·기관·연기금이 주어'를 같은 단위 안 출현으로 봤다 |
| CAP 이익 실현 | 같은 문장에 익절·수익·올라서·벌고가 있으면 E로 옮긴다(표에 'CAP 이익 실현 문장→E') |
| 부정어 | lexicon §3 목록 + 아님·아냐·아닌·아닙('폭락 아님'이 문서 예시라 목록에 없는 활용을 더함). 안·못은 단독형과 안팔·안사·안던만. 원래 부정 뜻을 담은 표현(없·못·않·아니·안이 든 표현)은 판정에서 뺀다 |
| 부정·질문 규칙 적용 | lexicon §3 표의 묶음만: E·F(버림/질문은 따로), CAP(부정→RES, 질문→HES), LL·LS(부정은 '레버리지 거부'로 빼고 질문은 셈), NOV(부정 버림, '지금 사도·지금 들어가도·지금 들어가면·지금 진입'은 질문형만), BUY(부정 버림). 그 밖의 묶음은 규칙 없음 |
| BULL·BEAR 부정 | 단어 뒤 같은 문장 3자 안 부정어면 부호를 뒤집는다. 앞쪽은 보지 않는다(문서가 '뒤 3자'만 말함) |
| 질문형 | 그 단어가 든 문장(끝 기호 포함)에 ?나 질문 어미가 있으면 |
| 가격 서술 문장 | 수치%·포인트 + 지수·종목명(별칭 포함) + 움직임 동사가 한 문장에 → 심리 묶음(E·F·CAP·HES·FO·RES·ANG·BUY·KX·KR·NOV)과 BULL·BEAR에서 뺀다. LL·LS·MC·PX·주제·별칭에는 걸지 않았다 |
| 2배·3배 | 공백 지운 앞뒤 5자 안에 ETF·레버·종목 별칭·대문자 티커(2~5자)가 있을 때만 |
| 10년 뒤 | 같은 단위에 1인칭(M10: 저는·제가·나는·내 계좌·제 계좌·제 평단·저도·단독 '전')이나 들고·물려·계좌가 있을 때만 |
| 잡음 거르기 범위 | 뉴스형 글 제목·본문, 지운 댓글, 정치 잡담(정치어 출현 2회 이상 + 시장어 0, 트럼프·연준·금리는 시장어)을 모든 묶음에서 뺐다. 주제·별칭도 기사 글을 빼므로 정밀도가 낮게 잡히는 쪽이다 |
| 인용 | '>'로 시작하는 줄, 한 줄 안 300자 이하의 “…”·"…"를 지우고 매칭한다(보여 주는 본문에는 남긴다) |
| 주식전문가(단독) | 단위에서 공백·ㅋㅎㅠㅜ·문장부호를 뺀 것이 '주식전문가'뿐일 때 |
| ㅋ4개 이상 + 2인칭 | 단위에 ㅋ 4개 이상 + 단독 2인칭(너·너는·너가·너도·너희(들)·너네·니가·니들·니네·님·님들·님아·님은·님이·님도·당신(은·이·도)·댁(은)). 문서에 2인칭 목록이 없어 정했다 |
| 적중 단위 | 그 층의 적중이 1개 이상인 단위. 표시는 그 층의 적중 전부(⟦k:단어⟧). 단어 정밀도는 표시된 적중마다 센다 |
