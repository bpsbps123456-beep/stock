## 창
| 항목 | 해석 |
|---|---|
| 경계 | 모든 창은 [open, close) 반열림. '마감 분 포함, 다음 분은 다음 창'(§2.1)과 같다. W_KR(D) = [P 08:00, D 08:00) KST, W_U(D) = [P 08:30 ET, D 08:30 ET)를 tz 변환으로 KST에 놓는다(서머타임 21:30, 해제 22:30) |
| 미국 강건판 09:00 ET | [P 09:00 ET, D 09:00 ET). '09:00에 닫는다'를 국내 '08:00 전에 닫는다'와 같게 읽어 08:59까지 포함했다(더 이른 마감) |
| 고정 24시간판 | 국내는 문서의 "(D−1 08:00, D 07:59]"를 24시간 [D−1 08:00, D 08:00)로 읽었다(문자 그대로면 23시간 59분). 미국 고정 24시간판 [D−1 08:30 ET, D 08:30 ET)는 문서에 없는 확장이라 설명용으로만 둔다 |
| 종류 | P와 D 사이 휴장일로 정한다. 없음 = weekday, 토·일만 = weekend, 평일 휴장 포함 = holiday. `over96`은 길이 > 96시간(정확히 96시간인 K2026-10-06·10-12는 표시 안 함, 문서 "넘는") |
| 휴장 엇갈림 | 국내 창: 창 안 미국 세션 날짜(P..D−1)의 평일 가운데 KRX·NYSE 개장 여부가 다른 날이 있으면 표시. 미국 창: 창 안 KRX 세션 날짜(P+1..D) 기준 |
| 서머타임 전환 주 | 전환 시각이 창 안에 있거나 D가 전환 다음 월요일로 시작하는 주에 있으면 표시(자료 구간에는 없음) |
| 완전성 | 창 id는 완전한 창에만 붙인다: 열림 전에 저장 글이 있어야 하고(거꾸로 받기가 그 앞까지 내려옴), 마감 ≤ 컷오프 다음 날 0시. 지금은 7/13이 거꾸로 받는 중이라 국내 첫 창은 7/15, 미국 첫 창은 7/14다 |

## 글·댓글
| 항목 | 해석 |
|---|---|
| 첫 줄 | 같은 no의 줄을 (파일, 줄 번호) 순으로 놓고 첫 줄의 제목·본문·작성자를 쓴다. 같은 no가 두 파일에 있는 경우는 0건. 두 줄 글 1,863개 중 본문이 바뀐 글 4개, 제목 5개 |
| 수치 필드 | views·up·down·댓글 up/down은 units에 싣지 않았다. ncomment는 잘림 표지에만 쓴다 |
| 잘림 | `trunc_last` = 마지막 줄 ncomment > 그 줄 저장 댓글 수(5,132글). 수집기가 뺀 차단·스팸 댓글도 ncomment에 들어 있어 하한 표지다. `trunc_first`(5,119글)·`trunc_any`도 둔다. 창 잘림 비율 `trunc_share`는 10/17 감사 뒤 `trunc_first`로 센다(마지막 줄 ncomment에는 마감 뒤 주목이 섞인다, `results/audit_leak.md`) |
| 댓글 날짜 규칙 확인 | 원천은 '수집한 달력일(KST)'의 댓글만 시각으로 준다. 맞춘 줄 1,466개 모두 날짜가 하나였고, 날짜 붙은 댓글이 그 줄 날짜와 같은 경우 0, 24시간 안인데 날짜가 붙은 줄 10개(24시간 규칙이 아님) |
| 날짜 확정 | ① matched: 다른 줄에 같은 (해시, 본문, 시각)이 날짜와 함께 있으면 그 날짜. ② row: 줄마다 수집 날짜 범위 [lo, hi]를 세운다. lo = max(글 날짜(시각이 글 시각보다 이르면 +1), 날짜 붙은 댓글 최대 + 1), hi = S 날짜(시각이 S보다 늦으면 −1). 같은 줄에 matched가 하나라도 있으면 그 줄 날짜가 정해진다. 파일은 덧붙이기만 하므로 줄 순서 = 수집 순서이고, lo는 앞으로·hi는 뒤로 전파한다. lo = hi면 row. ③ latest: 범위가 남으면 hi(가능한 가장 늦은 날짜) |
| 늦게만 틀림 | 시각만 댓글은 언제나 hi(확실한 상한)에 놓인다. 그래서 실제보다 이르게 놓이는 일이 없다. 모순(lo > hi) 0줄 |
| 쓰지 않은 규칙 | '다시 받은 글의 첫 줄은 등록 24시간 안에 받았다'(수집기 코드 규칙)는 맞춘 7,148개·한 줄 row 819개와 모두 맞았지만, 자료가 아니라 코드 가정이라 날짜 확정에 쓰지 않았다 |
| 중복 제거 | 고유 키 = (해시, 본문, 확정 시각). 맞추지 못한 같은 시각만 키가 여러 줄에 나오면 같은 댓글로 보고 범위의 교집합(가장 작은 hi)을 쓴다 |
| 창 붙이기 | 단위(글·댓글)는 자기 시각이 든 창에 붙인다(`win_kr` 등). 그래서 창마다 마감 전 단위만 들어간다. 부모 글 창 기준은 `pwin_kr`/`pwin_u`, `pre_close_kr`/`pre_close_u`다. S 뒤 날짜로 놓인 댓글(10/16)은 어느 창에도 없다 |
| 글보다 이른 댓글 | 날짜 붙은 댓글 49개가 글 시각보다 이르다(`before_post`). 자기 시각으로 창에 붙이고, 120분 셈에서는 뺀다 |
| 줄기 | `root_cid` = 그 댓글이 마지막으로 나온 줄에서 바로 앞의 깊이 0 댓글. 깊이는 0·1·2가 있다 |
| 120분 | `in120`: 글 등록 분 ≤ 댓글 < 등록 분 + 121분(분 단위 포함, 마감 분 포함 규칙과 같게). `c120_kr`/`c120_u` = in120이면서 부모 글 창 마감 전인 댓글 수. `rank_ok_kr`/`rank_ok_u` = 등록 분 ≤ 마감 분 − 120분(국내 05:59) |

## 번호 증가·품질
| 항목 | 해석 |
|---|---|
| 경계 번호 | B(t) = dt < t인 저장 글 번호의 누적 최대(번호·시각 뒤바뀜 89건, 최대 2분을 흡수). 창 번호 증가 = B(close) − B(open), 결번율 = 1 − (B(open), B(close)] 안 저장 글 수 ÷ 번호 증가. 수집 실패로 버린 번호(세 번 실패)도 결번으로 셈한다(구별 불가) |
| 같은 요일 기준선 | 직전 같은 요일 완전 창 최대 8개(holiday 종류 제외), 3개 미만이면 결측. 자기 제외, 앞 자료만 |
| 장애 창 | 시간당 번호 증가 < 기준선 × 0.20(문서 그대로). 추석 휴장(9/24·9/25)의 미국 창처럼 휴장으로 조용한 창도 문자 그대로 걸린다. 휴장 표지와 함께 두고, 결측 처리 여부는 특징 단계가 정한다(걸린 창을 결측으로 두면 덜 넣는 쪽) |
| 스팸 파도 | 문서에 숫자가 없어 정했다: 시간당 번호 증가 ≥ 기준선 × 1.5 이면서 시간당 저장 글 < 기준선 × 1.2. 가격을 보지 않고 정했다. 비율 열(`ratio_no`, `ratio_saved`)을 함께 둔다 |
| 소금 연속성 | 날짜별 작성자 해시 집합의 직전 날짜 겹침률 = 겹침 ÷ 그날 작성자(latest 댓글 제외). 직전 8일 중앙값의 절반 미만이면 표지. 지금 0일, 최저 0.20은 월요일(전날 일요일 작성자가 적음) |
