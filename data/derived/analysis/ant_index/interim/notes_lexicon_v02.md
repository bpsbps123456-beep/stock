## 모호해서 정한 해석
| 항목 | 정한 해석 | 이유 |
|---|---|---|
| 정답 | 두 라벨러가 모두 '예'일 때만 정답이다. 불일치는 정답이 아니며 수를 따로 적었다 | 지시. 상한(한쪽 이상 예)은 참고로만 적었다 |
| 묶음 정밀도 판정 시점 | 단어를 빼기 **전** 표본 60개(CONV_BEAR 53개)로 판정한다 | 뺄 단어를 고른 표본으로 다시 재면 낙관 편향이 생긴다. 뺀 뒤 같은 표본 재추정은 표에 '참고'로만 둔다. 이 값이 60%를 넘는 실패 묶음(LL_KR 67%, RES 67%, BULL 64%, CHASE_SELL 86%, IPO 84%)도 실패로 둔다. 통과로 바꾸려면 v0.2로 새 가림 표본 60개를 뽑아 다시 재야 한다(이 단계에서 하지 않음) |
| '적중 10회 이상' | 라벨된 표본 안 적중 수다. 모집단 적중 수가 아니다 | 정밀도는 라벨이 있어야 잴 수 있다. 모집단 기준이면 라벨 2~3개로 단어를 빼게 된다 |
| 적중 세기 | 표시된 적중마다 센다. 같은 단위 안 같은 단어도 따로 센다 | notes_blind의 정의('단어 정밀도는 표시된 적중마다 센다')를 그대로 따랐다. 단위·단어를 하나로 묶은 판과 '한쪽 이상 예' 판은 민감도 표에 적었다. 주 판정과 다른 단어는 12개다(E 몰빵, F 폭락, RES 존버, BUY 분할 매수·물타기, BULL 반등, BEAR 폭락·인버스, REBUT 아닌데·오히려, CHASE_BUY 매수했·빚투) |
| 적중 판정 | 적중이 1개인 단위는 단위 in_sense, 2개 이상인 단위는 hits_in_sense[k]를 쓴다. 351개 단위에서 두 라벨러 모두 '단위 = 적중의 OR'이 맞았다 | — |
| 옮겨 온 적중 | 규칙으로 CAP에서 E·HES로 옮겨 온 적중 8개는 단어 정밀도에서 뺐다. 옮겨 간 층의 단어가 아니라 규칙을 잰 값이다 | 묶음 정밀도에는 그대로 들어간다 |
| 공백 변형 | 공백만 다른 같은 표현은 함께 뺀다(BUY 분할 매수·분할매수) | 매처가 같은 표현으로 센다 |
| 특수 규칙 항목 | MOCK_BEAR의 'ㅋ4개 이상+2인칭'은 §4의 '약세론 10'에 든 사전 항목이라 단어처럼 규칙을 걸어 뺐다(28적중, 25%). '주식전문가(단독)'은 표본 적중이 없어 남겼다 | 새 규칙을 만들지 않고 빼기만 했다 |
| 반어율 | 한쪽 이상이 반어로 본 단위 ÷ 표본 단위로 판정했다(더 엄한 쪽) | 최대가 LS 18%라 '둘 다 반어' 기준으로 바꿔도 30%를 넘는 묶음은 없다 |
| κ | Cohen κ를 묶음별로 냈다. 0.6은 §2.7의 LLM 라벨 기준이라 사전 판정에는 쓰지 않고 표시만 했다 | TILT_US κ 0.00은 라벨러 2가 60개 모두 '예'라 기대 일치가 관측 일치와 같아진 경우다(일치율 85%). SEMI·TILT_KR·ALIAS_SKH는 둘 다 모두 '예'라 κ가 정의되지 않는다 |
| BULL/BEAR 정확도(H06) | score200에서 사전 점수가 0이 아닌 글만 보고, 두 라벨러의 글 극성이 모두 사전 부호와 같은 비율로 판정한다. 라벨 일치 단위만 본 값, 3범주(0 = 중립) 전체 정확도, 재현율을 함께 적었다 | H06은 점수 0인 작성자를 빼고 셈하므로, 사전이 강세·약세로 가른 글이 맞는지가 그 측정이다 |
| H06 판 | v0.2로 판정했다(점수 ≠ 0 14개 중 10개, 71%, 95% 구간 45~88%). 후보판은 36개 중 16개, 44%로 실패다 | 단어는 정밀도 표본으로 골랐다. score200은 BULL·BEAR 정밀도 표본과 겹치는 글이 0개라 표본 밖 확인이다. 다만 14개뿐이라 얇다. 3범주 전체 정확도는 46%, 재현율은 10%다 |
| 측정 실패 묶음의 단어 | 지우지 않고 v0.2 목록에 남긴다. 상태는 lexicon_v02_full.json `status`에 둔다 | lexicon_draft §8: '그 묶음을 쓰는 가설은 LLM 라벨 지수로 대신한다'. 묶음 삭제 규칙은 없다 |
| 빼기 구현 | 뺀 단어도 가장 긴 표현 먼저 규칙에서 자리를 차지한 뒤 버린다. 규칙으로 옮겨 가는 적중은 원래 묶음 기준으로 막는다 | 목록에서만 지우면 '레버리지' 안의 '레버'가 자리를 다시 잡는다. 같은 틀에서 '레버' 적중이 3,385에서 11,474로 늘어 빼기가 무효가 된다. 막는 판은 남은 단어의 적중이 후보판과 똑같아서, 잰 정밀도가 그대로 적용된다(검증: 209,691단위에서 'v0.2 = 후보 − 뺀 단어' 불일치 0, 새 적중 0, 글 점수 불일치 0) |
| 파일 두 개 | `lexicon_v02.json`은 지시대로 층 → 단어 목록만 담는다(MOCK_BEAR에는 남은 특수 항목 '주식전문가(단독)' 포함). 매칭 규칙, 막을 단어, 판정은 `lexicon_v02_full.json`에 있다. 셈에는 `lexicon_v02_final.load_v02()`를 쓴다 | 단어 목록만으로는 막기를 나타낼 수 없다 |

## 측정 실패의 영향(§4 '쓰는 가설' 기준, 판정은 하지 않음)
- E·F 실패: 순심리 S의 재료다. H01 관문과 S를 쓰는 칸(H14·H15·H19·H24·H49·H51·H53), H05에 걸린다. H02 규칙상 TMP는 'S 묶음 정밀도 60% 미만이고 TMP가 품질을 통과할 때만' 쓴다.
- BULL·BEAR 묶음 정밀도 실패(48%·32%): 글 점수를 쓰는 H06·H09~H12·H22·H37, 그리고 반도체 글 D_SD를 쓰는 H10에 걸린다. H06의 별도 기준(score200 정확도)은 v0.2로 71%(14개)라 통과다. 두 기준이 엇갈린다.
- 통과 묶음: PX, LL_US(H31), LS, MC(H30·H33), ANG, KX, MEM(H50), SEMI(H10 태그), TILT_US·TILT_KR(H46), ALIAS 4개(H39+H48·H40·H41·H43 별칭).
