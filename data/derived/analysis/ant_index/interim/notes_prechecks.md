## n_eff·독립 묶음
| 항목 | 정한 해석 | 이유 |
|---|---|---|
| n_eff 식 | (n − h) ÷ (1 + 2Σ_{k=1}^{h} ρᵏ·max(0, 1 − k/h)), ρ = 이웃 창 AC1, 0~0.99로 자름(음수는 0) | §2.7 MDE 표의 숫자(95·41·33·27, ρ 0.95·10일 ≈ 10)를 그대로 재현하는 식이다(테스트). 음의 ρ를 0으로 자르면 n_eff가 커지지 않는다(보수) |
| AC1 | 두 창 모두 값이 있는 이웃 쌍만, 쌍 5개 미만이면 결측 | 결측 창을 건너뛰어 잇지 않는다 |
| 뒤 구간 투영 | 2026-06-01~10-23 실제 거래일(KRX 98, NYSE 102; 10/16~10/23은 exchange_calendars 세션)에 지금 AC1을 넣었다 | 문서의 '약 96'은 어림값이다 |
| 독립 묶음 | '구간마다 h일 넘게 떨어진 독립 묶음 8개 이상'을 간격 ≥ h+1창(엄함)으로 읽고 판정에 썼다. 간격 ≥ h(겹침 없음)도 표에 둔다 | '넘게'를 글자대로 읽은 쪽이 더 엄하다 |
| 횡단면 칸(H39+H48·H40·H41) | 시간 묶음으로 셈: 21일 목표라 뒤 구간 주 21개 중 21일 목표가 끝나는 16주에서 5주 간격 → 4묶음 < 8 → 자동 설명용 | 문서가 횡단면을 예외로 두지 않았다. 종목 사이도 같은 주의 시장 충격을 함께 받아 독립이 아니다. **문서 의도(§5.3 '표본이 가장 많은 방향 칸')와 부딪힐 수 있어 사용자 확인이 필요한 해석이다** |
| 사건형(H24·H25·H26) | 독립 단위 = 사건 묶음. §2.7 최소 표본(구간마다 8)을 H24 행 규칙(2026 합 8 미만이면 판정 불가)과 함께 걸었다 | 앞 구간 3개는 이미 끝난 구간이라 확정이다. 뒤 구간 5개는 10/14까지라 10/15~10/23에 3개가 더 생겨야 8이 된다 |

## 상관·겹침 문턱
| 항목 | 정한 해석 | 이유 |
|---|---|---|
| 문턱 판단 | Pearson과 Spearman 중 하나라도 문턱을 넘으면 '넘음' | 더 엄한 쪽 |
| corr(U, N)(H04) | 판정 자격 창의 등록 rz8끼리(18창). 4창판·원값·미국판은 참고 | 문서 문장이 'corr(rz8 U, rz8 N)'이다. 18창이라 전체 자료에서 다시 잰다. 4창판은 0.899로 문턱 바로 아래 |
| corr(SH, A)·corr(K, A)(H54·H55) | 문자 그대로 SH·K 원값 × A(rz8)를 주로 썼다. 회귀에 같이 드는 rz8끼리(A6·A7 × A)와 원값끼리도 표에 둔다 | 원값끼리 Spearman 0.801은 요일·활동 추세가 섞인 값이라 문턱 판단에 쓰지 않았다(정의된 A는 rz8). A7은 5창뿐이라 판단에 안 썼다 |
| corr(A4, A)(H36) | 등록판은 90일 이력 때문에 0창이라 못 잼. 30일 4창판은 참고 | 문서에 H36 문턱 숫자가 없다(A에 잔차화하는 설계) |
| LL 신호와 NS20 겹침(H34) | NS20 = 판정 자격 창 NS 몫의 20창 평균(가격 잔차화 전). LL 신호 = LL_US 20창 변화(H31 특징)와 20창 평균 두 판. 둘 다 상위 15%(H31 보조 문턱 85)를 켜짐으로, 겹침 = 둘 다 켜진 창 ÷ NS 켜진 창 | 문서에 신호 정의가 없다. 전 표본 순위를 썼으니 판정이 아니라 설명용 점검값이다. 0/7이라 어느 문턱 읽기에서도 70%와 멀다 |
| D_SD와 B(H11) | D_SD 본판이 0창이라 원값 D_SD_raw(표 20 이상 26창)로 보고만 했다 | 문서는 '보고한다'만 요구한다 |

## 행별 가격 전 규칙
| 가설 | 정한 해석 |
|---|---|
| H16 | 사건 뉴스형 결측 = 그 창 사건 뉴스 글 0개(feat_text와 같은 규칙). 33.3% > 30% |
| H26 | 하락 상태일 = D−1 종가 ≤ 60거래일 최고 종가(D−1 포함) × 0.90인 D. 구간 배정은 D 기준. 뒤 구간은 D = 10/15까지 |
| H36 | 하락 조건 국면 = D−1 종가 기준 r20 ≤ 0인 날의 연속 구간(길이 1일도 국면). 5일 이상인 국면 수도 json에 둔다 |
| H37 | 행 규칙(분모 5 이상인 날 60%)은 계산된 창(30일 이력이 찬 창) 기준 65.7%로 통과로 봤다. 예열 창까지 넣으면 38.3%다. 그러나 분모 < 5로 비는 몫이 34.3%라 §2.7 30% 규칙에 걸린다 |
| H09 보조 코스닥 태그 | 이름 30개 사전이 없어 '코스닥' 낱말만 쓴 하한판이다. 봇·연재를 빼지 않아 표는 그 하한판 안에서는 많게 잡힌 쪽이다 |
| H23 | M9: 수치(%·퍼·프로, 배) 앞뒤 10자 안에 맥락어가 있고 제외어가 없을 때. 부호는 수치 앞 +/−·플러스/마이너스가 먼저, 없으면 맥락의 양·음 낱말(한쪽만 있을 때만). '수익률'은 부호 낱말로 보지 않았다(뺀 뒤 '수익'을 찾음). '배'는 앞 부호가 없으면 맥락으로만. M10 '전'은 앞뒤가 공백·문장부호인 홑낱말만. 주장 수는 단위(글·댓글) 수로 셌다. 주판은 M9+M10(1인칭)이다 |
| H24 사건 | KOSPI 또는 하닉 r/σ60 ≤ −2(σ60 = 그날 앞 60개 일수익 SD)인 세션일, 같은 날은 하나, 앞 사건 뒤 5거래일 안이면 같은 묶음(이어지면 계속). feat_text의 사건 표지와 같은 정의다. KOSPI만 판도 함께 둔다 |
| §12.4 급락 시작 | leverage_flood `stage2_eval.events`와 같은 정의(5일 고점 대비 −8% 확인, 고점 다음 날이 시작, 10거래일 안이면 같은 사건). KOSPI 2026 8건이 §12.4 목록과 같고, SOX는 §12.4의 7건 + 10/08(10/14 종가로 확인된 새 사건) |

## 외부 자료(#11)
- 가격 이력은 색인(날짜·시각)만 보고 값은 버렸다. 값 비교(네이버 ↔ yfinance KOSDAQ 시가)는 2025-01-02~01-09만 했다. 이 구간은 모든 포럼 창(2026-07-14~)보다 앞이라 어떤 창의 마감 뒤 값도 아니다.
- KIND·SEIBro·연준·BLS는 공개 첫 화면에 HTTP 요청만 보냈다(응답 코드·크기만 기록). 내려받은 KIND 목록은 저장하지 않았다.
- 8월 규제 시행일·예탁원 보관 상위·KOSPI200 야간선물은 저장소 문서·코드를 찾아봤다(ant_index 폴더 제외). 웹 검색은 쓰지 않았다.

## '측정 실패'를 자동 설명용과 따로 둔 이유
- §2.7 '자동 설명용'은 결측률·상관·겹침 문턱만 말한다. 사전 묶음 정밀도 미달은 lexicon §8('그 묶음을 쓰는 가설은 LLM 라벨 지수로 대신한다')과 H01·H02 규칙이 다룬다. 그래서 표에서 따로 적었다. TMP가 없으므로 지금은 그 칸들을 사전으로 판정할 수 없다.
