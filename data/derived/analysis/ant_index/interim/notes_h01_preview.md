## 관문 셈
| 항목 | 정한 해석 | 이유 |
|---|---|---|
| HAC(5) | Newey–West(Bartlett, 지연 5). 표준화한 S를 표준화한 r에 회귀한 기울기(= Pearson)의 t. 작은 표본 보정 n/(n−k), p는 자유도 n−k인 t 분포 | 정규 근사보다 p가 크다(보수) |
| 지연 짝 | 원래 창 위치 차가 정확히 l인 행끼리만 짝짓는다. 뺀 창 양옆을 잇지 않는다 | 빠진 창을 건너 이으면 지연 구조가 바뀐다 |
| Spearman | 쓰는 표본 안에서 순위를 매긴 뒤 같은 HAC 회귀 | — |
| 양측 p | 판정 위치는 양측 p로 봤다. 단측(예상 부호 +) p도 json에 있고, 이번에는 결론이 같았다 | 양측이 더 엄하다 |
| 급락 4일 | 7/29·7/30·7/31·10/13은 달력일이다(HYPOTHESES.md 본문: 7/29~31 글 폭증·7/29 바닥, 10/13 급락일). 주 읽기 = 그 달력일과 시간이 겹치는 창을 모두 뺀다(D = 7/29·7/30·7/31·8/03·10/13·10/14, 54창). 'P가 그날'(56창)과 'D가 그날'(56창) 읽기도 함께 냈다 | 가장 많이 빼는 읽기. 세 읽기 모두 Pearson·Spearman ≥ 0.15였다 |
| 급락 제외판 p | 관문 문장은 '0.15 이상'만 요구한다. p는 참고로만 적었다 | 문장 그대로 |
| 결번율 통제 | H01 특징 칸의 '결번율을 통제한다'는 M0 달력·품질 블록에 결번율을 넣는 것으로 읽었다. 관문 상관은 문장대로 원 상관이고, 결번율 부분 상관도 함께 냈다(두 칸 모두 기준을 넘음) | 엄한 읽기(둘 다 넘어야 함)에서도 결론이 같다 |
| 원형 이동 p | §2.7 p 계산 ①을 21~(N−21) 이동으로 함께 냈다. N = 60이면 이동 19개, 최소 p 0.05 | 관문 문장은 HAC(5) p다. 이동 개수가 적어 0.05 아래가 나올 수 없으므로 참고로만 둔다 |
| 강건 ②·③ | 기여가 가장 큰 2창(z_S·z_r가 추정 부호 쪽으로 가장 큰 2창), 열어 본 8일과 겹치는 창을 뺀 판을 보조로 냈다 | 관문 기준에는 없다. 1차 판정의 강건 규칙을 미리 본 것이다 |

## M0 (§2.3 한국)
| 항목 | 정한 해석 | 이유 |
|---|---|---|
| \|r(D−1)\| | 뺐다 | max(r,0) − min(r,0) = \|r\|이라 세 열이 완전 공선이다. 두 열이 r과 \|r\|을 모두 담는다 |
| r5·r20·r60 | P 종가 ÷ P보다 5·20·60세션 앞 종가 − 1 | §2.0 '그 세션까지의 수익' |
| DD20 | P 종가 ÷ P까지 20세션 최고 종가 − 1 | §2.0 |
| ln RV20 | P까지 20개 일 로그수익의 SD(ddof 1)의 로그. 종가만 쓴다(고가·저가 없음) | 시가·고가·저가를 버렸다 |
| 거래대금 이상치 | ln(P 거래량 ÷ P 앞 20세션 평균 거래량). 거래량 0(6/29)은 결측, 평균은 15세션 이상일 때 | yfinance ^KS11에 원화 거래대금이 없다. 거래량(주식 수)으로 대신한 것이라 저가주 쏠림이 섞인다 |
| VKOSPI 1일 변화 | 못 넣었다 | yfinance ^VKOSPI 0행, 저장소 수동 CSV는 날마다 이어진 값이 아니다 |
| SOX·EWY | u 세션의 종가 대 종가 수익 | §2.3 '직전 미국 세션 수익' |
| 블록 | 한국 가격 = max·min(r), r5, r20, r60, DD20 / 미국 밤 = SOX, EWY / 변동·거래 = ln RV20, 거래량 이상치 / 달력·품질 = 달력 더미 + 결번율 | H01 네 블록 이름 그대로. 결번율은 '품질'이다 |
| 달력 더미 | 주말 창·연휴 창(창 종류), 휴장 엇갈림, 방학 달(D의 달이 1·2·7·8월), KOSPI 옵션 만기(둘째 목요일, 휴장이면 직전 세션), 미국 월물 만기(셋째 금요일, 같음), FOMC 성명일, 실적일(NVDA·MU·AVGO·하닉·삼전) | §2.4. 서머타임 전환 주·조기 폐장·정치 기간은 자료 구간에 없다 |
| 일정이 창에 드는 규칙 | 일정일 e ∈ [P, D−1](달력일)이면 1. 미국 장전(08:30 ET)·장후(16:xx ET)·FOMC(14:00 ET)는 KST e 21:30 ~ e+1 06:00이라 W_KR(D) 안이고, 국내 장전·장중 발표(e 08:00 뒤)도 같은 규칙이 된다 | 발표 시각을 하나씩 확인할 원천이 없어 한 규칙으로 정했다 |
| 만기일 옮기기 | 달력 끝(10/15) 뒤 날짜는 옮기지 않는다 | 첫 실행에서 10/16(셋째 금요일)이 10/14로 끌려와 마지막 창에 잘못 들어간 것을 고쳤다(테스트 추가). 결과는 고친 뒤 값이다 |
| 한 점 더미 | 표본 안에서 1이 2개 미만인 더미는 뺀다(급락 제외판의 FOMC: 1개) | 한 창만 맞추는 열은 R²만 부풀린다 |
| 실적일 원천 | yfinance `get_earnings_dates`의 날짜만(EPS 열은 버림). 삼전은 잠정실적일이 없어 확정 실적일(7/29)로 대신했다 | §2.4는 '사전 공개 일정'이다. 실적일은 몇 주 전에 공지된다 |
| CPI·고용·MSCI | 못 넣었다 | BLS 일정 403(가격 전 점검), 웹 검색 금지, MSCI 날짜 원천 없음 |
| 적합 | 표본 안 OLS 한 번. §2.3의 확장 OLS(최소 120창, 월 1회 재적합)는 창이 60개라 못 한다. 그래서 R² 분해만 내고 X⊥ 잔차는 만들지 않았다 | 확장 적합 없이 만든 잔차는 앞 가설에 쓰면 누출이다 |
| 부분 R² | (블록을 뺀 모형의 잔차 제곱합 − 전체 모형의 것) ÷ 뺀 모형의 것. 함께: 단독 R², 뺄 때 줄어드는 R², Shapley 몫(네 블록의 16개 부분집합, 합 = 전체 R²) | '블록별로 나눠 본다'를 합이 맞는 Shapley로도 보였다 |
| 귀무 | S를 21~(N−21) 원형 이동하고 M0 행렬은 그대로 둔다. 전체 R²와 블록 부분 R²의 분포 | S와 r20·DD20처럼 느린 열끼리는 우연만으로도 R²가 크다. iid 기대값(k ÷ (n−1))만 적으면 이것이 가려진다 |
| 하닉 블록 | M0 위에 하닉 max·min(r), r5, r20을 더한 보조판 | '같은 정의의 하닉 칸'을 보이려고. M0 정의에는 넣지 않았다 |
| 지연 1~20 | corr(S(D), r(P−k)), P−k = P보다 k세션 앞 KRX 세션 | H01 '지연 1~20일은 설명용'. 지난 가격만이다 |
