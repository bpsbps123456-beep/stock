# notes_labeler1: 독립 라벨러 1 판정 기준

> 읽은 것: `HYPOTHESES.md`, `HYPOTHESES_addendum1.md`, `lexicon_draft.md`, `interim/notes_blind.md`, `results/blind_samples.json`. **`blind_key.parquet`와 다른 라벨러의 파일(코드 포함)은 열지 않았다.** 가격 자료도 보지 않았다. 동결 문서 세 개는 고치지 않았다.
> 판정 방식: 2,353단위(정밀도 표본 2,153개, score200 200개)를 묶음별로 사람이 직접 읽고 판정했다. 판정은 `results/labels_1_raw/<묶음>.txt`에 예외 목록으로 적었다. `code/labeler1_assemble.py`는 그 목록을 표본 id에 붙이고 범위를 검사하기만 한다. 단어 규칙이나 정규식으로 판정하지 않았다.
> 표본의 사전 판독 칸(`hits[].dict_reading`)은 보지 않았다. 판정에 영향을 주지 않게 출력에서 뺐다.

## 출력 형식 (`results/labels_1.json`)
| 필드 | 값 |
|---|---|
| id, set, bundle | 표본 그대로. score200은 bundle = "score200" |
| in_sense | true/false = 그 단위가 묶음 정의(blind_samples `bundles[].meaning`, lexicon §4 머리말, HYPOTHESES §4)대로 쓰였나. score200은 null |
| irony | true/false = 반어·조롱·농담이라서 겉뜻을 진지하게 말한 것이 아닌가 |
| polarity | BULL·BEAR·score200만 "강세"/"약세"/"중립". 나머지는 null |
| hits_in_sense | 적중이 2개 이상인 단위에만 둔다. 적중 k마다 true/false. 단어 정밀도용 |

## 공통 해석 (모호하면 덜 세는 쪽)
| 항목 | 정한 해석 |
|---|---|
| 단위 판정 | 적중 중 하나라도 묶음 뜻이면 단위는 '예'. 같은 단위에서 뜻이 아닌 적중은 hits_in_sense에서 false |
| 화자 | 감정·행동 묶음(E·F·CAP·HES·FO·RES·NOV·CHASE·CONV·BUY)은 **글쓴이 자신의** 상태·행동이거나, 지금 시장 군중의 상태를 사실로 전할 때만 '예'로 했다. 남의 과거 행동 서술, 일반론·조언, 가정·반사실("팔았어야", "했으면"), 부정, 조롱 대상 묘사는 '아니오' |
| 반어 | 비꼬기·조롱·말장난·흉내 내기처럼 겉뜻을 진지하게 말한 것이 아닐 때만 '예'로 했다. 과장이지만 진심인 고통 표현("살려주세요 ㅠㅠ", "한강 갈 판")은 반어가 아니다. 반어로 쓴 묶음 단어는 in_sense도 '아니오'로 했다(예: 농담인 "수익인증", "축포로 마이너스") |
| 다른 뜻 | 동음·관용어(이 바닥=이 업계, 거품 물다, 인내심 바닥, 살려고요=사려고, 사용자 이름 @가즈아·@TQQQ·@분할매수, 삼성 병원)는 '아니오' |

## polarity 기준
- 단위 전체에서 글쓴이가 시장·종목 방향을 어떻게 보는지다. 단어 하나의 방향이 아니다.
- 근거 없이 지난 하락이나 상승을 사실로만 적은 글은 '중립'이다. 슬픔·원망만 있고 방향 의견이 없어도 '중립'이다. 단, 하락이 계속된다고 보는 뜻이 드러나면 '약세'다.
- 강세와 약세가 섞이거나(단기 약세·장기 강세) 조건부 시나리오만 있으면 '중립'이다.
- 뉴스를 옮긴 글은 기사 내용의 방향을 따랐다(예: 콜옵션 매수 급증 기사 = 강세).
