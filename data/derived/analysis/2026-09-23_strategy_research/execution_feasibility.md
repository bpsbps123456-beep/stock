# 연구 규칙의 향후 실행 가능성 점검

작성일: 2026-09-27. 이 문서는 실행 가정 감사다. 미국 종목 제한 재계산은 별도 `us_only_feasibility/`에 저장한다.

결론: 과거 공개 자료와 직전 가격으로 종목 순위·현금 판단을 결정하는 규칙은 반복 실행할 수 있다. 현재 엔진은 실제 계좌의 체결·잔고를 재현한 시스템이 아니며, 기존 수익률을 그대로 개인 계좌에서 재현할 수 있다고 해석하면 안 된다. ETF 대비 2~3배 미래 수익의 증거도 아직 부족하다.

## 현재 코드에서 확인한 사실

| 항목 | 현 상태 | 실전 모의운용에 필요한 보완 |
| --- | --- | --- |
| 신호 결정 | 거래 날짜보다 앞선 스냅샷과 이전 가격을 사용, 동점은 고정 종목 순서 | 입력 자료와 규칙 버전을 결정 시점에 고정·저장 |
| 자료 공개 | 과거 기준일은 있으나 당시 최초 공개 시각은 미입증 | 실제 다운로드 시각과 의사결정 마감 시각 기록, 늦게 온 자료는 다음 회차 사용 |
| 시장·환율 | 같은 날짜의 여러 시장 종가·환율을 하나의 평가 축으로 합산 | 실제 시간 순서별 가격·환전·현금 가용성을 사용 |
| 배분 금액 | 당일 모든 시장 종가 손익 반영 후 총자산으로 재배분 | 앞서 닫힌 시장의 주문에 나중 시장 종가가 쓰이지 않도록, 주문 전 확인한 잔고·가격으로 수량 고정 |
| 체결 | 종가에서 소수 단위 금액 배분과 고정 비용을 가정 | 증권사별 거래 가능 종목, 최소 주문 단위, 호가·미체결·부분 체결·실제 비용 반영 |
| 교체일 | 전체 시장 날짜 합집합에서 첫 주간·월간 세션 | 사용자 거래 시장과 시간대별 영업일·휴장·재시도 규칙 고정 |
| 현금 전환 | 시장 상태는 매일 계산하지만 교체일에만 실행 | 주간 방어인지 매일 방어인지 사용자 실행 일정과 일치시킴 |
| 종목 수 | 최대 개수 제약이며 신호가 적으면 소수 집중 가능 | 최소 분산·종목별 최대 비중을 원한다면 새 제약으로 다시 검증 |
| 제공물 | 과거 보유·교체 CSV와 연구 보고서 | 다음 회차의 유지·편입·제외 후보, 근거·입력 시각을 사전에 기록하는 모의 신호 출력 |

특히 같은 날짜의 글로벌 종가를 합친 뒤 주문 금액을 정하는 방식은 엄격한 실시간 주문 재현이 아니다. 종목 순위에 미래 가격을 쓰지 않는다는 검사만으로 주문 금액과 체결까지 미래 정보가 없다고 보장할 수 없다. 기존 단일 날짜 축의 결과는 이 한계를 가진 연구 근사치다.

## 다음 연구의 순서

1. 사용자의 실제 거래 가능 시장과 주문 가능 시간대를 먼저 확정한다.
2. 해당 시간 전에 확보한 자료만으로 후보와 규칙을 동결한다. 시장을 제한하거나 주문 시각을 바꾸면 새 전략으로 취급하며 이전 수익률을 옮겨 붙이지 않는다.
3. 실제 거래 시간 순서·주문 단위·가용 현금을 반영하여 같은 과거 기간을 재검증한다.
4. 미래 날짜의 신호를 결과가 나오기 전에 저장하고, 이후 관측된 체결 가능 가격·비용으로 모의계좌를 평가한다.
5. 같은 시작 원금·기간의 TIME·KoAct 직접 보유와 비교한다. 손실이 난 뒤 규칙을 바꾸면 별도 버전으로 구분한다.

## 사용자 실행 시간 반영

- 사용자 확인: 한국시간 오전 08:00~오후 23:00에 주문 가능.
- 사용자의 최종 정정에 따라 매매 대상은 **미국 상장 주식만**, 최대 10종목이다. 한국·일본·홍콩·중국 상장 종목은 후보에서 제외한다. 두 ETF는 매매 신호의 원천과 성과 비교 기준으로 유지한다.
- 사용자가 주문을 넣을 수 있다고 확인했다. 주문 가능을 전제로 진행하고 증권사 확인을 선행 조건으로 삼지 않는다.
- 사용자가 매수·매도 비용이 0원이라고 확인했다. 현재 기본 연구에서는 명시적 매매비용을 차감하지 않으며, 지연 효과도 비용 0 조건에서 따로 평가한다. 과거 15/30bp 결과는 이전 가정의 기록으로 보존한다.
- 미국 정규장은 뉴욕시간 09:30~16:00이다. 한국시간으로 서머타임에는 22:30~다음 날 05:00, 표준시에는 23:30~다음 날 06:00이다. 따라서 정규장 수동 주문을 연중 같은 방식으로 수행하려면 현재 시간 범위와 맞지 않는다.
- 사용자가 주문 가능을 확인했으므로 위 시간 차이는 연구 중단 사유가 아니다. 다만 주문 가능 여부가 종가 체결·소수 단위 목표 배분을 보장하는 것은 아니며, 장전 거래의 성과를 정규장 종가 성과로 대체하지 않는다.
- 주문 시각, 자료 마감 시각과 실제 가격을 고정한 새 실행 모형을 먼저 검증한다. 기존 종가 기반 높은 수익률을 새 방식의 예상 수익으로 사용하지 않는다.

근거: [NYSE 정규 거래시간](https://www.nyse.com/markets/hours-calendars), [NIST 미국 서머타임 규칙](https://www.nist.gov/pml/time-and-frequency-division/popular-links/time-frequency-z/time-and-frequency-z-d).

미국 종목 제한의 영향은 기존에 선택된 규칙을 고정하고 재계산한다. 기존 글로벌 실험의 고수익 후보를 미국 전용 성과로 재표기하거나, 새 결과를 보고 가장 좋은 규칙을 다시 골라 독립 검증으로 부르지 않는다. 전체 펀드 수량 보정을 끝낸 뒤 미국 종목만 선별한다.

고정 후보 비교는 [미국 종목 제한 진단](us_only_feasibility/report.md)에 저장한다. 이어 미국 가격 관측 거래일을 평가 달력으로 쓰는 별도 전수 탐색을 `us_only_experiment/`에 분리한다. 두 실험 모두 같은 과거 자료를 다시 사용하는 추가 연구이며 미래 검증이 아니다.

사용자 비용 0원 정정을 반영한 최신 비교는 [비용 0원 미국 전용 연구](us_only_experiment/zero_cost/report.md)에 저장한다. 종가 체결 가정과 실제 체결가격 차이는 별도이며, 확인되지 않은 비용률을 다시 임의 차감하지 않는다.

아직 실제 주문, 자동매매, 정기 알림 또는 모의운용 일정은 설정하지 않았다. 주문 가능을 전제로 미국 전용 수익률·낙폭·지연 민감도 검증을 진행한다.
