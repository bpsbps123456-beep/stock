# 양봉 비율 3단계 — 시간봉 조합 사전 등록 (2026-10-25, 결과 보기 전)

## 질문 (사용자, 2026-10-25)

> 시간봉을 바꾸면서 조합해봤어?

BRIEF2는 신호를 40분봉에 고정했다. 시간봉을 바꾼 것은 '큰 봉 일치' 판정(160·320분·일봉)뿐이었다. 이번에는 **신호 시간봉 b × 구간 판정 시간봉 z** 조합을 잰다.

## 정의 (`code/zones_mtf.py`)

- 신호 s: b분 연장 봉, N10 개수 따라가기 0.5/0.5. 원안 규칙에서 시간봉만 바꾼다.
- 판정
  - z = b: ER20 ≥ 0.3, ADX14 ≥ 20, |p20 − 0.5| ≥ 0.1
  - z > b: 위 셋을 z봉에서 계산한 것에 AGREE(z봉 원안 상태 = s)를 더한다
  - z봉 값은 그 b봉 마감 시각에 이미 끝난 마지막 z봉이다. 일봉은 정규장 16:00 ET 마감 뒤에 반영한다.
- 구간
  - +1: 추세이고 s = 1 → 보유
  - −1: 추세이고 s = 0 → 현금
  - 0: 애매 → 행동 A0(현금) 또는 A2(동결)
  - 기준 A3: b봉 원안 그대로
- 예열: 7/17 전은 1시간봉(6/1~)으로 묶어 앞에 붙인다. 평가는 7/17부터의 5분봉 봉만 쓴다. 그래서 40분 원안의 고르기 구간 값이 BRIEF2와 조금 다르다(MU 실제 +25.8% → +27.3%). 확인 구간은 같다.

| 축 | 값 | 개수 |
|---|---|---|
| 신호 시간봉 b | 10·20·30·40·60·90·120·180·240분 | 9 |
| 판정 시간봉 z | b, 2b, 4b, 8b(≤ 960분), 일봉 | b마다 4~5 |
| (b, z) 쌍 | | 43 |
| 판정 | z = b면 3개, z > b면 4개 | 163 |
| 행동 | A0·A2 | 2 |
| 전략 | 163 × 2 + 원안 9 | **335** |

- 미리 정한 기본값: b 40, z 160, AGREE, A0. 큰 봉과 작은 봉이 같이 '보유'일 때만 들고 있는다.

## 평가 (BRIEF2와 같은 틀)

- 144종목, 고르기 7/17~9/4, 확인 9/8~10/22.
- 판: 실제(깨어 있음 + 편도 0.1%, 주), 실제 비용 0(깨끗한 타이밍), 이상적(모든 봉, 비용 0).
- 고르기 1위: 고르기 구간 실제 판 144종목 중앙 (수익 − 같은 비중 수익)이 가장 큰 전략. 비용 0 판 1위도 따로 본다.
- 시간봉 조합 지도: (b, z, 판정)별 확인 구간 중앙 (수익 − 같은 비중), (수익 − 같은 b 원안), (낙폭 − 같은 비중 낙폭).
- 진단: 비용 0 판에서 원안 보유로 잰 '추세 봉 초과 − 애매 봉 초과'(종목 중앙), 고르기·확인 각각.
- 귀무: 판정 flag만 공통 k 원형 이동(달력 같은 시각 칸, 15 ≤ k ≤ 54, 40개). 같은 고르기 절차를 귀무에도 돌린다. 163개 계열에서 통과 수를 귀무와 비교한다.

## 채택 기준 (미리 정함)

1. 고른 전략(또는 기본값)이 확인 구간 실제 판 144종목 중앙에서 다음을 모두 만족한다.
   - 같은 b 원안보다 수익과 낙폭이 모두 낫다.
   - 같은 비중 그냥 보유보다 수익이 높거나 같고 낙폭이 얕거나 같다.
   - 귀무 95분위를 넘는다.
2. 비용 0 판에서도 같은 방향이다(비용 회피만으로 생긴 우위가 아님).
3. 이웃 조합(b나 z가 한 칸 옆)에서도 부호가 같다.

모두 통과하면 '쓸 만한 조합'이라고 말한다. 아니면 탐색 결과로 보고한다.
