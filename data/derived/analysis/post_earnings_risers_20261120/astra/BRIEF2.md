# Astra 2단계 과제서 — 사례 조사(눈가림)와 아이디어 (2026-11-20)

1단계 고맙다. 가설서(H01~H18)는 잠긴 것으로 본다. 네 자료(위키·공매도·내부자)로 만드는 요인은 **Claude가 네 정의 그대로** 계산한다. 너는 아래 A·B만 한다.

## 지금까지 Claude가 본 것(참고)
두 펀드 보유 종목 2026 실적 600건(발표 당시 보유 235건)에서, '개미 관심' 측정(SEIBRO 한국인 매수 비중·Top50 진입, OCC 고객 콜 급증, 발표 전 거래량 급증, 발표 전 20일 상승)은 실적 뒤 20일 흐름을 **어느 쪽으로도 안정되게 가르지 못했다**(상반기와 하반기 부호가 뒤집힘). EPS 서프라이즈도 반응일만 맞혔다. 반면 많이 오른 종목은 시즌마다 **한 테마로 몰렸다**(1분기 광통신, 2분기 칩 설계, 3분기 소프트웨어·코인 관련). 그래서 숫자 밖의 '무슨 일이 있었나'를 사례로 본다.

## A. 눈가림 사례 조사 (필수, 가장 먼저)
`astra/cases_blind.csv`의 56건(C01~C56). 절반은 실적 뒤 크게 오른 종목, 절반은 같은 시즌·비슷한 반응일·비슷한 크기인데 하위권에 머문 짝이다. **어느 쪽인지는 알려 주지 않는다.** `../results/cases.csv`·`events.csv`·`features.csv`는 A를 다 끝낼 때까지 열지 않는다.

사례마다 `astra/cases/Cxx.json` 하나를 바로바로 쓴다(56개 모두 있어야 A 완료). 조사 창은 **발표일 −10일 ~ 반응일 +30일(달력일)**. 사례당 검색은 6회 이내.

| 칸 | 내용 |
|---|---|
| `case_id`, `ticker` | |
| `catalysts` | 아래 분류표 코드마다 `{code, date, one_line, url}` 목록. 같은 코드 여러 건 가능 |
| `pre_retail_hype` | 발표 **전** 개인 투자자 쏠림 증거(레딧·WSB 화제, 개인 순매수 상위 보도, 한국 '서학개미' 기사, 개인 인기 종목 목록): `"있음"|"없음"|"모름"` + 근거 url |
| `narrative_new` | 실적 발표·콜에서 **시장이 몰랐던 새 이야기**(새 고객·새 사업·처음 공개한 숫자·새 시장 규모)가 처음 나왔나: `"예"|"아니오"` + 한 줄 + url |
| `expectation_before` | 발표 전 시장 분위기 한 줄(기대 높음/낮음/의심, 근거 url) |
| `confidence` | 높음/중간/낮음 |

분류표(고정, 결과 보기 전 정함):

| 코드 | 사건 |
|---|---|
| C1 | 이름 있는 고객·계약·수주 발표(하이퍼스케일러·정부 등) |
| C2 | 제품·기술·디자인윈 발표 |
| C3 | 애널리스트 상향·목표가 대폭 상향·신규 커버리지 시작 |
| C4 | 지수 편입 발표(S&P 500·400, 나스닥100 등) |
| C5 | 인수합병·전략 투자(예: 대형사의 지분 투자)·행동주의 |
| C6 | 증자·전환사채·대주주 대량 매도(보통 악재) |
| C7 | 동종·고객사 실적·발표의 파급(예: 하이퍼스케일러 설비투자 상향) |
| C8 | 정책·규제·정부 사업·관세 |
| C9 | 실적 뒤 추가 가이던스 상향·투자자의 날·경영진 변화 |
| C10 | 자사주 매입·내부자 매수 |
| C11 | 공매도 보고서·소송·사고 등 악재 |
| C12 | 공매도 급감·숏스퀴즈 보도 |
| C0 | 창 안에 회사 고유 사건 없음 |

규칙: **사건을 적는다, 주가 움직임을 적지 않는다.** "주가 급등"만 쓴 기사는 촉매가 아니다. 반응일 뒤 주가 수익률은 찾아보지 않는다(기사에 나오면 무시하고 사건만 적는다). 모르면 `"모름"`.

A를 다 쓰면 `astra/cases_summary.csv`(case_id × 코드 0/1 열, pre_retail_hype, narrative_new)를 파이썬으로 만든다.

## B. 눈가림 해제 뒤 아이디어 `astra/IDEAS.md`
