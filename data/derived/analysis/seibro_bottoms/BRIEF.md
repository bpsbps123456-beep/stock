# SEIBRO 한국인 미국 주식 매매 — SOXX 큰 바닥 전후 공통점 (설계, 2026-11-03, 흐름–사건 연결 전)

## 1. 질문 (사용자, 2026-11-03)

- "SOXX가 엄청난 하락을 했던 바닥 지점과 관련해 세이브로 한국인 매수·매도에 어떤 공통점이 있는지 최근 3개년 정도 조사."
- 설명용 사건 연구다. 바닥 전(내려가는 동안)·바닥·바닥 뒤(반등)의 한국인 결제 흐름에서 공통점을 찾는다. 그 공통점이 '가짜 바닥'(급락 중 바닥처럼 보였는데 더 빠진 날)과 다른지 본다.
- 이미 알려진 것(`../seibro_flows/report.md`): 국내 투자자는 SOXX가 떨어진 **같은 미국 거래일**에 SOXL을 순매수한다(일별 상관 −0.75, 하루 앞뒤 ≈ 0). 그래서 '바닥에서 SOXL을 산다'는 공통점은 가격 메아리일 가능성이 크다. 핵심은 그 메아리를 넘는 차이가 있는지다.
- 매수 추천·주문 계산은 하지 않는다. 데스크 규칙 채택은 사용자가 정한다.

## 4. 흐름 측정 (미국 거래일 단위, 26개)

N⁺ = 합집합 주식(NONEQ·DUMMY 제외, 신규 상장 28일 제외 `../seibro_flows/derived/ipo.json`)의 순매수 양수 합. ΣB_eq = d1 목록 주식 매수 합. 목록 밖 상품은 0이 아니라 '50위보다 작음'(절단)이다. 절단 비율을 측정마다 보고한다.

| 코드 | 측정 | 식(창 합으로 계산) |
|---|---|---|
| A1 | 전체 거래 규모 | d3 Top50 tot 합 |
| A2 | 전체 매수 규모 | d1 Top50 buy 합 |
| A3 | 전체 매도 규모 | d2 Top50 sell 합 |
| A4 | 합집합 순매수 합 | 합집합 전체 net 합(근사) |
| X1 | SOXL 순매수 | n(SOXL) |
| X2 | SOXL 매수 | b(SOXL) |
| X3 | SOXL 매도 | s(SOXL) |
| X4 | SOXL 순매수 비중 | n(SOXL) ÷ N⁺ |
| X5 | SOXL 거래 몫 | t(SOXL) ÷ A1 |
| X6 | SOXL 매도 ÷ 매수 | s ÷ b |
| H1 | SOXS 순매수 | n(SOXS) |
| H2 | SOXL 강세 몫 | b(SOXL) ÷ (b(SOXL) + b(SOXS)) |
| H3 | 주식 인버스 매수 몫 | Σb(EQ_INV) ÷ ΣB_eq |
| H4 | 주식 인버스 순매수 | Σn(EQ_INV) |
| L1 | 3배 롱 순매수 | Σn(EQ3L) |
| L2 | 3배 롱 순매수 비중 | Σn(EQ3L) ÷ N⁺ |
| L3 | 단일종목 레버리지 롱 순매수 | Σn(lev_long & single) — 2026-07-31 뒤 구조 단절 |
| L4 | 지수형 레버리지 대 현물 매수 | Σb(lev_long & IDX) ÷ Σb(spot 주식) |
| R1 | 1배 반도체 순매수 | §2 목록 |
| R2 | 1배 지수 ETF 순매수(반도체 제외) | EQ_INDEX & L = 1 & sign = 0 & semi 아님 |
| R3 | 채권·현금 순매수 | BOND·CASH & sign ≥ 0 |
| R4 | 그 밖 1배 개별주 순매수 | EQ_SINGLE & L = 1 & sign = 0 & R1 아님 |
| R5 | 인컴(커버드콜) 순매수 | utype INCOME |
| C1 | SOXL 보유 좌수 변화 | 창 시작 전 보관일 → 창 끝 보관일 Δlog(보관 ÷ SOXL 종가) |
| C2 | SOXL 보관 비중 | 창 끝 보관(SOXL) ÷ 보관 Top50 합 |
| C3 | 보관 Top50 합 변화 | 창 시작 전 → 끝 Δlog |

- 보관 날짜 D가 어느 미국 거래일까지의 결제를 담는지는 SOXL로 실측한다(Δ좌수 × 종가 ~ 거래일별 순매수, 지연 0~4). 결과 지연으로 보관을 미국 거래일에 붙인다.

## 6. 공통점과 차이 (설명용, 칸 수 고정)

| 항목 | 규칙 |
