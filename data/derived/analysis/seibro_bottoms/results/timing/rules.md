## 후보
- profile `holdout_2026.csv`에서 2023~25 B10 7개로 고른(selected) 칸 중 창 W1·W2·W3, E(메아리 잔차) 칸 10개. P 칸 15개는 순수 메아리라 뺀다.
- contrast `holdout_2026.csv`의 2023~25 짝 4국면으로 고른 5칸(모두 E, W1~W3).

## 고르기 식 (최대 2개)
| 지문 | 출처 | 식 | 결과 |
|---|---|---|---|

## 날마다 판정
| 항목 | 정의 |
|---|---|
| 창 | 미국 거래일 t에 끝나는 창: FP1 L = 5(t−4~t), FP2 L = 1(t) |
| 값 | `measures_win.E_exp`(창 끝 < t 행만 적합, 최소 250행). 없으면 판정 안 함 |
| 켜짐 | 상태 dd60(t) ≤ −0.10 그리고 FP1: E_exp ≥ +0.5 / FP2: E_exp ≤ −0.5 (BRIEF §6 \|z\| ≥ 0.5 문턱) |
| 진입 e | t 흐름을 아는 날(`known_settle`, 다음 KSD 영업일 09:00 KST) 이후 첫 NYSE 세션 시가(`entry_settle`) |
| 성과 | SOXX R_h = Close[e+h−1] ÷ Open[e] − 1, h = 5·10·20 |
| 비교 | 켜진 날 대 같은 상태(dd60 ≤ −0.10, E_exp 있음) 모든 날, 대 모든 날(E_exp 있음). 2023~2025(고른 해)와 2026(확인) 따로 |
| 보고 | 켜진 날 수, 서로 다른 하락 구간 수(상태 날이 5세션 넘게 끊기면 새 구간), B10 바닥 ±5세션 안 비율, 2026 차이의 원형 이동 귀무(2026 안 모든 이동) |
| 성격 | 설명용. 겹친 수익(켜진 날끼리 창 겹침)이라 날 수 ≠ 독립 표본 |

- FP1·FP2 고르기는 이 표로 끝낸다. 결과를 본 뒤 문턱·창·상태 조건을 바꾸지 않는다.
