# Codex 독립 탐색 과제 (SOXL 긴급탈출·바닥, 2026-11-20)

작업 폴더: `data/derived/analysis/soxl_escape_20261120/` (저장소 루트 기준).
먼저 같은 폴더의 `BRIEF.md`와 `code/harness.py`, `code/_smoke.py`를 끝까지 읽는다. 구간·채점·미래 정보 금지 규칙은 BRIEF.md를 그대로 따른다.

## 역할
Claude 쪽 에이전트 6명이 따로 같은 문제를 탐색 중이다(구조 이탈선, 이평선·추적 손절, 실패 랠리, 오실레이터 바닥, 이격 바닥, 구조 반전 확인).
너는 **다른 각도의 독립 탐색자**다. 그들의 파일(`code/`의 네 것이 아닌 파일, `results/`의 네 것이 아닌 파일)은 읽지 않는다.

## 할 일 (순서대로, 모두 필수)
1. 다음 각도를 우선 탐색한다(이 밖의 아이디어도 좋다):
   - 거래량·흐름: 거래량 급증(z-점수), 세션 VWAP와 VWAP 표준편차 밴드, 이탈 봉의 거래량이 '진짜 붕괴'와 '털기'를 가르는지.
   - 시간대: 개장 직후 30분·점심·마감 1시간의 이탈과 바닥 성격 차이(한국시간 23:30 개장).
   - 다중 시간봉 합의: 1분·3분·15분 신호가 겹칠 때만 쓰는 방식.
   - 이탈 뒤 '계속 빠짐(continuation)'과 '털고 반등(shakeout)'을 실시간 값으로 가르는 분류(사후 라벨로 학습한 규칙이면 TRAIN에서만 만들고 TEST로 확인).
2. EXIT 최종 1개, BOTTOM 최종 1개를 TRAIN만으로 고르고 TEST 성적을 그대로 적는다. 시험한 설정 수를 숫자로 적는다.
3. 결과는 `results/codex.json`(파이썬으로 저장), 코드는 `code/codex_*.py`, 사람이 읽을 요약은 파이썬으로 `results/codex_summary.txt`에 쓴다(한국어, 결론 먼저, 표 하나, 근거 3~5줄, Pine으로 옮길 정확한 규칙 정의).

## 금지
- `harness.py`, `BRIEF.md`, `docs/`, 다른 갈래 파일 수정 금지. 버그를 찾으면 요약에 적는다.
- git 커밋·푸시 금지(Claude가 한꺼번에 커밋한다).
- 자료 재수집 금지(`cache/SOXL_1m.parquet`만 사용). 웹 검색 불필요.
- 중간에 스스로 멈추지 않는다. 요청이 실제로 거부되는 한도 오류가 날 때만 `results/codex_progress.txt`에 진행 상황을 적고 멈춘다.

## 끝났다는 증거
`results/codex.json`과 `results/codex_summary.txt`가 있고, `py code/codex_<메인>.py`로 다시 돌리면 같은 숫자가 나온다.
