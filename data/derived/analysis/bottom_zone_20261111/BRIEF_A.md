TASK_A.md의 19 단일 + 8 결합 + 7 고점 보조 = 34설정을 그대로 쓴다. X1 30%·70%는 판정 밖 민감도 두 칸뿐이다.

| 항목 | 고정 구현 |
|---|---|
| 새 판 | 2023-01-02~2026-11-11 평일의 결제 4순위·보관을 이 폴더에 다시 수집한다. 실패·빈 응답도 남긴다. 원응답 XML은 날짜별 gzip, 분석용 parsed JSON은 재생 가능 캐시로 둔다. 가격 3종은 각각 새 Yahoo 전체 응답, CNN도 원응답 저장 |
| 날짜 | 기존 calendar_map.seibro_of와 XKRX−2026-06-03, XNYS를 재사용한다. 예측상 같은 결제 날짜의 거래일을 묶어 균등 분배한다. 기존 cal 묶음 7개가 모두 pred2인 것을 확인했다. 미래 거래량을 보는 가운데 이동중앙값으로 묶음을 바꾸지 않는다 |
| 공개 | 결제 다음 KSD 영업일, 보관 둘째 영업일 09:00 KST. 같은 공개 세션에 여러 원거래일이면 유효성 검사 전에 최신 날짜 선택. 새 결제 없는 세션은 NO_NEW_SOURCE이며 전일 값을 전달하지 않는다. 보관은 마지막 공개 관측을 유지하고 원날짜를 남긴다 |
| 금액 | SOXS·SOXL ISIN 사슬은 기존 classes.csv·build.load_classes를 따른다. 네 순위 합집합에서 상품을 한 번만 센다. Top50 전체 매수는 매수순위 d1 합, 전체 순매수는 네 순위 합집합 net 합. DUMMY 제외. Top50 밖 상품·미공개·부분 관측은 NaN이며 0이 아니다 |
| 보관 | 보관금액 / 해당 보관 날짜 이하 마지막 SOXL 종가 = 좌수. 해당 날짜에 담긴 거래일은 기존 seibro_of(t)≤D인 마지막 t. 공개된 보관을 거래일 격자에 놓고 5세션 전 공개 잔고와 비교한다. 보관 갱신 없는 날의 유지값과 나이를 보존 |
| X1 | 원거래일 t의 과거60일 최근 최고일 p부터 t까지 진행 최저·5일 매수 최대를 계산한다. 5일 합이 결측이면 NaN. X3의 가격 근접 조건도 그 보관이 담은 원거래일까지의 가격만 사용 |
| 백분위 | 기존 build.pct_rank: 당일 포함250미국세션, 최소120유효값, 중간동률. strict 5세션 합, 비율은 합/합 |
| 뉴스 | census의 published_at 날짜 다음 정규장부터 5세션 유지. 한 노트의 여러 행·같은 날 같은 family는 중복 제거. --news-series는 date를 공개 날짜로 해석. census 마지막 공개일 뒤는 미수집으로 UNKNOWN; 마지막 날까지 노트 없는 날만 OFF |
| CNN | UTC timestamp를 미국 날짜로 변환해 직전 세션에 해당하는 일별 score 사용. 해당 날짜 없으면 UNKNOWN. 과거 게시시점 버전은 알 수 없다 |
| 대표 | 하락 상태·2024-01-02~2025-12-31 관찰일, 결과도2025-12-31에 절단한다. ON 유효 채점5건 이상·OFF1건 이상 중 Z ON−OFF 최대. 정확한 동률이면 TASK 표 순서 우선. 후보 없는 계열은 대표 null·조합 해당 입력 UNKNOWN |
| 결과 | SOXX 진입 시가 대비 진입 포함20세션 최저 종가. 완성 창 성공1·실패0, 미완성도 이미 문턱 아래면0, 그 외NaN. 10·20일 수익은 각각 완성 창만. 최소 종가 평균은 완성20창만. −3·−8도 같은 규칙 |
| 짝 | 같은 해·상태·해당 신호 OFF·Z 유효. 해의 같은 상태 전체에서 DD60·직전5일 단순수익·직전1일 단순수익을 표본표준편차로 표준화. ON 날짜순 greedy 최근접 유클리드, 중복 금지·±2세션 제외·거리 동률 이른 날짜. ON이 OFF보다 많으면 미매칭 수와 짝이 있는 ON 성적 별도 표시 |
| 사건 | 전체2024~최신 격자에서 첫 ON부터10세션 이상 간격(연도·반기 경계 초기화 없음). OFF도 같은 방식. 사건 표의 가격 짝은 사건ON을 대상으로 다시1:1매칭 |
| 원형 이동 | 각 해의 전체 세션 신호(UNKNOWN 포함)를 정수 offset으로 원형 이동, 상태·결과는 고정. ON−OFF Z비율 차이의 단측 개선 검정,10,000회·시드20261111. 양쪽 집단 없는 이동은 유효 귀무에서 제외하고 수를 기록. Holm은2026 대표6개+K3의7칸만 |
| 바닥 | B10 기존10날짜 고정, 새 가격으로 종가를 읽는다. 구역−10~+5·시가≤바닥종가×1.05 AND 하락 상태. 일별 첫 켜짐과10세션 간격 사건 기준 정밀도·재현율을 구분. 가격 짝도 동일 산식 |
| 재계산 | 별도 verify_A.py는 run_A의 평가·짝·바닥 함수를 호출하지 않고 가격에서 Z·거리·사건·구역을 다시 계산한다. 미래 가격·수급·CNN 값을 바꾸는 신호 불변 시험을 포함 |
