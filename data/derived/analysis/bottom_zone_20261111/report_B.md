검색은 공개 뉴스의 색인에 의존한다. 비공개 기관 노트 전수 표본은 아니다. RSS 날짜는 원문의 뉴욕 공개 시각이 아니라 피드 날짜 대용이다. 검증되지 않은 날짜·변경 전후 값·목표 연도·Citi 부서 차이를 재확인해야 한다. 제목에서 급락 근거를 못 읽은 행의 after_selloff=N은 수치상 하락 상태가 아니라 명시 근거 미확인을 뜻한다.

사전 고정 커밋은 4452ced이다. news/freeze_B.json은 이 **B1 부분 표본**과 검색 원자료만 동결하며 B2나 전수 검토 완료를 인증하지 않는다. SHA-256은 Git의 Windows 줄바꿈 변환을 견디도록 CRLF를 LF로 바꾼 바이트 기준이다. 가격 연결 전 동결 커밋을 남긴 뒤 인계한다. 전체 py -m unittest는 **509 tests / 36.352s / OK / 종료 코드 0**으로 통과했다. 출력은 news/unittest_output.txt, 다음 작업은 news/PROGRESS_B.md를 따른다.
