## 3. 묶음별로 왜 못 살아남았나

- **F1 시가 범위 돌파.** Zarattini 원형(범위 반대쪽 끝 손절)은 N=1에서 sel 평균이 actual −0.06, std −0.01이었다. '손절 뒤 반대로 1회'는 더 나빴다(−0.48 / −0.25). sel에서 양수였던 칸의 공통점은 '손절 없음'이다(즉시 진입·돌파 확인 둘 다 비슷). actual은 서머타임 날 10:00~11:00 되돌림을 맞아 std보다 낮았다.
- **F2 소음 경계 추세.** actual 288칸이 sel에서 모두 t < 0이었다. 10:00 뒤 진입이 되돌림에 걸렸다. std 1위는 09:35~09:44 진입에서만 벌었고, 시가 체결로 바꾸면 −0.016으로 무너졌다.
- **F3 갭·프리장.** 296칸 중 sel t 최대가 1.39로 우연 수준이다. 1위(09:00 프리장 갭 반대)의 sel 이익은 갭 하락 날 SOXL 매수 53일(+0.84%)이 거의 전부였고, 상위 5일을 빼면 +0.03%였다.
- **F4 되돌림.** 10:00 전에 거스르면 진다(09:35 시작 t 중앙값 −0.77). std는 10:00에 마감해서 되돌림 창이 없고, 60칸 모두 t < 0이었다. actual 1위는 sel 28건 중 19건이 5~6월 급등기에 몰렸고, conf에서는 SOXS 진입 6건이 평균 −2.28%였다. 얼린 id의 'vp3'·'vp1'은 문턱 색인이다(level 3 = 4%, level 1 = 2%).
- **F5 개장 전 상태.** 상태로 추세와 되돌림을 바꿔 끼워도 1위들이 상태 없는 'N1 추세 → 10:00'(sel std +0.59%, t 1.90)을 넘지 못했다. 문턱은 sel(상반기 상승장) 분위로 정한 값이라 장세가 바뀌면 날 비율부터 달라진다.

## 4. F1-A 재구현과 감사 ('관찰'이라 검증함)

- **며칠에 몰림.** conf actual 날별 수익은 중앙값 0.0, 표준편차 3.80%다. 상위 1·3·5일을 빼면 +0.081·−0.063·−0.211이고, 상위 5일 중 4일이 7월이다. 위아래 5일씩 자르면 +0.409다. 양쪽 꼬리(최고 +7.8%, 최저 −11.9%)가 평균을 좌우한다.

- **체결 민감도.** 다음 봉 시가 체결(지연 없음)이면 9~10월이 −0.158이라 탈락이다. 사람 지연을 늘리면 1분 +0.174, 2분 +0.133, 3분 +0.123, 5분 +0.086이다.

- **자료.** Alpaca SIP 1분봉 2024-12-02~2026-10-28, 정규장 478일이고 첫 90분 봉 누락은 0이다. 야후와 겹치는 1,890봉 중 1,889봉은 같다. 2026-10-15 09:30 봉은 야후 쪽이 깨져 있다(시가 = 고가 = 종가). 차트 출처에 따라 F1-A 신호가 21일 중 1일 갈린다.

  - 호가 30일에는 conf 6일·2025 16일이 섞여 있다(비용 입력이라 방향 중립).
- **1분 지연.** 09:31~09:38은 1분 |수익| 중앙값이 0.39~0.50%라 지연 감도가 크다.
- **장세 전환 위험.** 2025에는 F1·F3 후보가 손실 쪽이었다(t −1.6~−2.0). 방향이 맞는 해와 틀리는 해가 갈린다.
- **표준시 30분 창.** 11/2~3월에는 24:00 KST = 10:00 ET라 정규장을 30분만 쓸 수 있다. std판 9개는 모두 탈락이다.
