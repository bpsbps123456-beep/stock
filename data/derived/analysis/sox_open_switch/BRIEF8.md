# SOXL 프리장 급등 뒤 SOXS 매수 검증 계획

2026년 11월 4일 사용자 가설을 수익 결과 계산 전에 고정한다. 사용자는 본장 시작 30분 전인 09:00 ET 진입과 SOXL 급등 시 SOXS 매수를 확인했다. 청산은 본장 첫 30분 안이다.

## 가설과 시각

| 항목 | 고정 정의 |
|---|---|
| 급등 | 09:00에 완성된 SOXL 08:59 봉 종가 ÷ 직전 거래일 정규장 마지막 1분봉 종가 − 1 |
| 주 기준 | +5% 이상. 사용자 수치를 대신한 사실 가정이 아니라 이번 시험의 설계값 |
| 민감도 | +3%, +8%. 결과 1위를 다시 주 기준으로 고르지 않음 |
| 판단 | 실제시각 09:00. 09:00 이후 SOXL 가격은 신호에 쓰지 않음 |
| 진입 | 사람의 1분 지연을 반영해 09:00 시작 봉 종가, 실제시각 09:01에 SOXS 매수 |
| 주 청산 | 09:58 시작 봉 종가, 실제시각 09:59. 겨울에도 KST 23:59라 주문 가능 시간 안 |
| 청산 민감도 | 실제시각 09:45. 총 3문턱 × 2청산 = 6설정 모두 공개 |
| 횟수와 조건 | 하루 한 번, SOXS 하나. 목표가·손절·추가 매수·재진입·다른 거름 조건을 추가하지 않음 |
| 거래 가격 | 기존 code/lib.py Engine과 cost_table.json 재사용. 시장가 체결은 연구용 가격 근사이며 장외 실제 주문 유형을 확정하지 않음 |
| 원가격 확인 | 신호·진입·청산의 원분봉과 실제 거래량 확인. 앞 종가로 채운 빈 봉을 체결로 인정하지 않음 |

## 자료와 평가

- Alpaca SIP 분할 반영 1분봉. 기존 `cache/alp1m`과 `cache/alp1m_recent`를 겹치는 OHLC가 같은지 점검한 뒤 합친다. 별도 합친 캐시는 재생성 가능하므로 Git 제외 경로에 둔다.
- 주 평가: 2026-01-02~2026-11-03. 1~6월과 7~11월 3일, 뒤 구간의 7~8월과 9~11월 3일을 따로 공개한다. 2025는 고르기에 쓰지 않는 장세 위험 보조다. 2024년 이전 성과는 계산·판정하지 않는다.
- 기존 F3C가 09:00 프리장 진입을 포함했고 2026 자료는 다른 연구에도 반복 사용했다. 이번 앞·뒤 비교는 역사 자료 재검토이며 처음 보는 독립 확인이라고 부르지 않는다. 다음 독립 확인은 이 정의를 고정한 이후의 종이 기록이다.
- 주 통계는 전체 거래일 평균(무신호일 0), 보조는 매매당 평균·중앙·승률·최악 매매·활동일·복리·최대 낙폭(시작 자본 1 포함)이다. 매매당 수익과 계좌 수익을 구분한다.
- 날짜 묶음 부트스트랩 10,000회(seed 20261104)의 95% 구간과 참고용 단측 꼬리 비율, 뒤 구간 6설정의 Holm 보정값을 공개한다. 선택편향을 제거한 확증 통계로 표현하지 않는다.
- 상위 수익 2일 제거와 기존 반 호가 비용 2배를 각 구간에 적용한다.
- 대조는 같은 시각 매일 SOXS, 매일 SOXL, 신호일에 같은 시각 SOXL, 그리고 2026 월별 신호 수를 맞춰 무작위로 고른 날 SOXS 10,000회다. 文턱이 같은 달의 아무 날보다 나은지 본다. 무작위 모집단도 동일한 원분봉·전일종가 유효 조건을 만족하는 날로 한정한다.
- 신호일 실제 진입 매도호가·청산 매수호가를 Alpaca SIP에서 별도로 확인한다. 시각 직전 120초 창에서 가장 최근 호가를 조회하고, 호가 나이 30초 이하·양수 bid/ask·bid ≤ ask·양쪽 잔량 양수만 인정한다. 분할 전 실제 호가와 분할 반영 봉의 가격 단위 차이는 같은 시각 봉/호가 비율로 감사하고, 손익은 같은 날 실제 호가끼리 직접 계산한다. 진입/청산의 가격 단위 비율 차이가 1% 이상이면 자료 정합성 문제로 분리한다. 시각·호가 나이·양수·역전·호가 누락을 기록한다. 유효 호가가 없으면 실제 호가 결과에서 제외하고 건수를 공개한다.

## 판정

주 가설 +5%·09:59가 뒤 구간에서 양수이고, 앞·뒤 각각 양수이며, 비용 2배·뒤 구간 상위 2일 제거에서도 양수인지 본다. 뒤 구간 신호 20건 미만이거나 95% 구간에 0이 있으면 확인 부족으로 남긴다. 월내 무작위 날짜 대조보다 나은지도 별도로 판단한다. 민감도 1칸만 좋다고 채택하지 않는다. 자료 누락·희소성·실측 호가 결과가 결론을 바꾸면 이를 주 결론에 반영한다.

이 시험은 매수 추천·주문 계산이나 기존 데스크 매매 규칙 변경이 아니다.
