# 반도체 약세에 언제 쉬고, 언제 대기를 풀까

2026-11-22 · 클로드의 경고·대피·재매수 지표 · 기존 9종목과 비교군 10종목

**지표에는 SOXX 약세와 회복 첫날을 표시할 만하다.** 6월 이후 기존 9종목에서 시장이 약할 때 새 진입을 한 번 보류하면 종목별 최대낙폭 중앙값이 −34.1%에서 −28.0%로 줄었다. 기존 보유까지 청산하면 −20.0%로 더 줄었지만, 1~5월에는 이 정책이 원 지표 수익률 중앙값을 +178.8%에서 +133.9%로 낮췄다. 회복을 이틀 기다리면 급락 때 손실을 더 줄이는 대신, 반등 초입에 시작한 거래를 통째로 놓칠 수 있었다. **기존 보유 일괄 청산과 이틀 의무 대기는 연구 기록으로 둔다.**

2026-11-20 미국 정규장 마감 기준 SOXX의 시간봉과 일봉은 모두 약세였다. 10/30 마감에 다시 켜진 경고가 이어지고 있어, 이 설계의 차트 표시는 **반도체 약세 · 신규 진입 대기**다. [일자별 시장 상태](market_states.csv)

## 청산과 신규 진입 대기의 차이

각 칸은 종목별 **수익률 중앙값 / 최대낙폭 중앙값**이다. % 단위이며 개별 종목의 모의계좌를 각각 계산했다. 최근 3개월은 6월 이후 구간에 포함된다.

| 지표의 행동 | 기존 9종목 1/2~5/29 | 기존 9종목 6/1~11/20 | 비교 10종목 6/1~11/20 | 기존 9종목 8/20~11/20 | 비교 10종목 8/20~11/20 |
|---|---:|---:|---:|---:|---:|
| 원 지표 | +178.8 / −25.5 | −16.4 / −34.1 | −7.3 / −29.0 | −3.4 / −16.6 | −4.9 / −16.7 |
| SOXX 두 주기 약세에 신규만 대기, 회복 1일 | +151.3 / −18.5 | −6.0 / −28.0 | −6.0 / −20.7 | −2.9 / −14.7 | +0.6 / −8.9 |
| 같은 대기, 회복 2일 | 0.0 / −15.2 | −7.0 / −20.0 | −4.5 / −14.6 | 0.0 / −7.0 | +0.2 / −6.5 |
| 같은 대기, 회복 3일 | 0.0 / −9.8 | −6.9 / −16.2 | +0.6 / −13.7 | 0.0 / 0.0 | 0.0 / −2.7 |
| SOXX 두 주기 약세면 기존 보유도 청산 | +133.9 / −18.2 | −0.7 / −20.0 | −1.8 / −14.6 | 0.0 / −13.2 | +2.8 / −7.2 |
| SOXX 시간봉 약세만으로 기존 보유도 청산 | +53.3 / −11.6 | +7.9 / −13.7 | −5.8 / −13.1 | +2.1 / −9.6 | −3.5 / −8.5 |

6월 이후 동시 약세에 **강제 청산을 추가**했을 때, 신규 대기만 한 경우와 비교해 기존 9종목은 수익 개선 4개·악화 4개·동일 1개였다. 비교군은 개선 5개·악화 4개·동일 1개였다. 10/15~11/20 최근 27거래일만 보면 기존 9종목 전부 두 정책의 수익률이 같았다. 빠른 시간봉 청산의 앞·뒤 구간 성적 차이도 컸다.

이틀 대기의 6월 이후 보유일 중앙값은 기존 9종목에서 122거래일 중 13일이었다. 원 지표는 46일이었다. 각 종목의 기준 지표를 실험과 같은 평균 노출로 낮춰 비교하면, 이틀 대기의 수익 차이 중앙값은 기존 9종목 −3.45%p, 비교 10종목 −3.39%p였다. 이 대조는 해당 구간이 끝난 후 보유 구간 수를 맞춘 뒤 기준 지표의 일일 순수익에 고정 배율을 적용했다. 매일 비율을 맞출 때의 추가 비용은 제외했다. 수익과 위험을 함께 평가하는 접근은 지수선물에서 손절 정책을 분석한 Kaminski·Lo도 사용했다. ## MU에서 대기를 하루 늘리면

| SOXX 회복 첫날 | 첫날 회복으로 허용한 MU 거래 | 이틀 회복과 새 종목 신호를 모두 요구한 결과 |
|---|---:|---|
| 9/17 마감 | 9/18 시가~10/9 시가 **+6.84%** | 상승을 놓침 |
| 10/28 마감 | 10/29 시가~11/2 시가 **−8.19%** | 손실을 피함 |

10/29 종가에는 SOXX 회복 상태가 이틀째였다. 이미 지나간 MU 신호를 다시 허용하는 별도 규칙이라면 10/30 시가에 들어가 11/2 시가에 끝나 **+0.54%**였다. 10/15~11/20 MU 전체는 첫날 해제 −8.19%, 이틀 뒤 **새 신호만** 허용 0%, 이틀 뒤 **진행 중 신호도** 허용 +0.54%였다. 다만 6월 이후 기존 9종목 전체에서는 이틀 뒤 진행 중 신호도 허용할 때 중앙 수익률 −20.67%, 새 신호만 기다릴 때 −6.99%였다.

6월 이후 19종목에서 이틀 대기가 추가로 막은 거래는 **33건, 서로 다른 SOXX 회복은 7번**이었다. 막은 거래 중 손실 19건과 이익 14건이 있었고, 원래대로 거래했을 때의 건당 평균은 +0.16%였다. 10/28 한 번에 MU·WDC·AVGO·MRVL 네 종목이 함께 걸렸고 모두 손실이었다. 이 반등을 통째로 빼면 남은 29건은 손실 15건·이익 14건, 평균 **+1.08%**였다. 9/4 회복 뒤에는 같은 대기로 AMD +17.88%를 놓치는 동시에 STX −11.82%를 피했다. 건당 평균은 회차 비교용이고 복리 계좌 수익률은 위 표에 있다. ## 시장의 범위와 봉의 길이

6/1~11/20에 **같은 두 주기 동시 약세**를 어느 ETF로 판단하는지 바꿨다. 아래 수치는 각각 기존 9종목 / 비교 10종목의 중앙 수익률이다.

| 시장을 판단한 ETF | 신규만 대기 | 기존 보유도 청산 |
|---|---:|---:|
| 반도체 SOXX | −6.04% / −5.98% | −0.65% / −1.81% |
| 나스닥100 QQQ | −4.79% / −9.20% | −2.43% / −5.68% |
| S&P 500 SPY | −15.59% / −13.90% | −8.37% / −6.97% |

기존 지표 종목에선 신규 진입을 거를 때 QQQ도 효과가 있었고, 섹터 비교군에서는 SOXX가 가장 나았다. 특히 10/15 이후 AMD는 SOXX 대기로 −30.72%에서 0%가 됐지만 SPY 대기로는 −20.13%였다. 여기서 매매한 대상은 같은 19종목이다. 미국 주식 전체에 대한 현금 전환을 검증하려면 매매 대상도 넓혀야 한다. [QQQ 운용사](https://www.invesco.com/qqq-etf/en/home.html) · [SPY 운용사](https://www.ssga.com/us/en/intermediary/etfs/spdr-sp-500-etf-trust-spy)

시간봉 EMA10·20은 일봉 EMA10·20보다 빨리 움직인다. 매 시간 종가를 쓰되 감쇠 속도를 10·20거래일로 맞춘 추가 대조에서, 6월 이후 강제 청산 중앙 수익은 기존 9개 −0.65%, 비교 10개 +0.10%였다. 일봉만 쓴 청산은 −0.65%, −2.76%였다. 시간봉 청산 수익 +7.90%는 짧은 평활 길이까지 포함한 결과다.

## 계산과 검증

- **시점과 체결**. 원 지표는 종목 정규장 일봉 종가가 EMA10·20 모두 아래면 다음 정규장 시가에 대피하고, 모두 위로 회복하면 다음 시가에 복귀한다. 두 선 사이에서는 직전 상태를 잇는다. 전날 마지막 정규장 40분봉 EMA100은 종목 경고선이다. 시장도 완성된 봉만 쓴다. 시간봉·일봉이 각각 두 EMA 아래인 상태에 모이면 약세, 위인 상태에 모이면 회복이고 엇갈리면 직전 결합 상태를 유지한다. 신규 대기 1·2·3일은 이 **허용 상태로 정규장을 연속 마감한 거래일 수**다. 하루 중 신호는 기록하고 주문 판단은 직전 정규장 마감으로 고정했다. 여름 한국 22:30, 겨울 23:30의 다음 정규장 시가로 체결했다. DELL은 처음 관측된 정규장 1분봉이 1~2분 늦은 날이 세 번 있었다. 뒤 구간에는 모두 정시에 시가가 있었다.
- **표본과 시세**. 원래 9개는 클로드의 실제 일봉 신호와 원 엔진에서 만든 시가·종가를 사용했다. 비교군은 2025-09-30 SOXX 공시의 미국 달러 보통주 중 원 9개를 제외한 비중 상위 10개다. 이 공시는 2025-11-26 공개됐다. 비교군은 SIP 30분봉 첫 시가·마지막 종가와 같은 일봉 수식, 시장은 SIP 정규장 10분봉으로 만든 시간봉·일봉을 썼다. 분할을 반영하고 2025년은 초기 상태 준비에만 사용했다. 각 종목의 정규장 시가·종가에서 달러로 평가했고, 실제 수수료 0원에 체결 오차 대용으로 편도 로그비용 0.001(약 0.10%)을 차감했다. 배당·현금이자·세금·환율은 제외했다. 낙폭은 장중 저점에서 더 깊을 수 있고, 직전 종가부터 첫 시가 사이의 갭은 기존 보유에 귀속했다. 장외 시세까지 측정한 [앞 연구](../report.md)와 평가 시각이 다르다. [SEC 공시](https://www.sec.gov/Archives/edgar/data/1100663/000207169125007653/0002071691-25-007653-index.htm) · [비교군과 공시 비중](universe.csv) · [Alpaca SIP 시세](https://docs.alpaca.markets/us/reference/stockbars)
- **시험 범위**. 기준 1개, SOXX 회복 1·2·3거래일 × 새 신호만 허용하거나 진행 중 신호도 허용하는 정책 6개를 비교했다. 강제 청산 대조 5개는 시간봉·일봉·두 주기·두 주기에서 진행 중 신호도 재허용·거래일 길이를 맞춘 시간봉이다. QQQ·SPY 각각 신규 대기와 청산 2개씩을 더해 고정 비교는 총 16개다. 시간 단위 일치와 QQQ·SPY는 본 결과를 본 뒤 확인한 민감도 대조다. 10/28 MU 손실은 설계 전에 알려져 있었다. 19개가 같은 시장 날짜를 공유하므로 19번의 독립 검증으로 셀 수 없다.
- **앞에서 골라 뒤에 적용**. 기존 9종목의 1/2~5/29 성적으로 진입 정책 7개를 평가했다. 최대낙폭 중앙값이 기준보다 깊은 정책을 제외하고 수익률 중앙값이 가장 높은 정책을 골랐다. 선택은 원 지표였다. 이를 6/1~11/20 고정 적용한 중앙 수익률은 기존 −16.41%, 비교 −7.33%다. 별도로 직전 완결 3개월마다 같은 기준으로 다음 달 정책을 골랐다. 6~11월 순서로 기준·1일 진행 중 허용·기준·1일 새 신호·2일 새 신호·1일 새 신호였다. 이동 적용 중앙 수익 / 낙폭은 6월 이후 기존 −6.31 / −29.15%, 비교 −1.46 / −27.49%, 최근 3개월 기존 **+2.87 / −13.91%**, 비교 **−0.62 / −8.93%**였다. 10월 선택은 9월 말까지의 데이터로 결정된다. 이번 후속 연구 전체는 과거 자료를 재생한 결과다.
