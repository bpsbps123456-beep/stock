# 메모리

## 종목
MU, SNDK, WDC, STX

## 섹터 특성
- HBM (고대역폭 메모리) → AI 서버 필수 부품
- NAND/SSD → 데이터센터 스토리지
- 사이클 산업이지만 AI로 구조적 성장 전환

## 종목별 투자 포인트

### MU
- HBM3E 시장 선도 / AI Megafab 투자

### SNDK
- WDC에서 분사 / NAND 전문 / 나스닥-100 편입 (4/20)

### WDC
- HDD + 엔터프라이즈 SSD / Q3 실적 4/30

### STX
- HDD 대용량 수요 + AI 데이터 스토리지

## 비교 포인트
- MU vs SNDK: HBM vs NAND 순수 플레이
- WDC vs STX: HDD/SSD 혼합 vs HDD 집중
