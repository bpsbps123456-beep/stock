# GBRC 투자 철학

## 핵심 원칙
> 정량(FY27·FY28 Forward PER)으로 **후보**를 고르고, 뉴스로 **타이밍과 확신**을 얻는다

## 왜 Forward PER인가
- 현재 PER이 아니라 미래 실적이 반영된 PER로 판단
- FY27·FY28 EPS 컨센서스 기준 → 성장이 실현됐을 때의 가치를 지금 산다
- FY28은 FY27 성장률 유지 가정 (추정치)

## 뉴스의 역할

| 뉴스 유형 | 의미 |
|---|---|
| 애널리스트 목표가 상향 | EPS·매출 추정치 상향 가능성 → Forward PER 하락 |
| 대형 계약 체결 | 성장률 추정치 신뢰도 상승 |
| 실적 서프라이즈 | 기존 추정치가 보수적이었다는 신호 |
| 다운그레이드 | 추정치 하향 가능성 → 현재 PER이 실제보다 낮아 보일 수 있음 |

## 의사결정 프로세스
1. 정량 스크리닝 (daily_analysis.py 실행)
2. 섹터 내 상대 비교 (같은 섹터끼리 PER·성장률 비교)
3. 뉴스 확인 (오늘 날짜부터 검색)
4. 매수/홀드/매도 판단 → decisions.md에 기록
