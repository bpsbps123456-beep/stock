# 옵션 요청·복기 시스템 (Options System Reference)

> 활성 범위: **Path-O 또는 사용자의 명시적 옵션 요청**
> 정기 펀드 브리핑의 선행 문서가 아니며, 명시적 옵션 요청이 없으면 옵션 스크립트를 실행하지 않는다.

---

## 운영 경계

- 옵션은 요청형 모듈이다. 정기 브리핑이나 펀드 추종의 선행 조건이 아니다.
- Path-O의 기본 목적은 전일 옵션 신호를 실제 가격과 대조하고 역전 사례의 돌발 재료를 검증하는 것이다.
- 새 옵션 스캔은 사용자가 옵션 흐름·순위·목표가를 명시적으로 요청했을 때만 실행한다.
- 이 문서는 개별 종목의 전통적 밸류에이션과 목표주가 산정 규칙을 다루지 않는다.
- 섹터·종목 매핑은 `watchlist.py`를 정본으로 사용한다.

### 구조적 필터
- **OPEX 당일 만기 제외**: 스캔일과 같은 날 만기는 자동 제외 (핀 리스크 방어)
- **소형주 유동성 할인**: 시가총액 < $2B → 최종 점수 × 0.85
- **어닝 ±3일 신뢰도 반감 (v3.4 신규)**: `next_earnings`가 -3 ~ +3일 범위면 score × 0.7. 어닝 직전 정보 비대칭 구간 + 어닝 결과는 옵션 데이터로 예측 불가 (CRWV/UUUU 미스 케이스 방어). 로그에 `earnings_proximity_flag: true` 기록.
- **데이터 검증 레이어 (v3.4 신규)**: iv_skew |값|>1.0 → N/A, term_structure는 near_iv<0.05 또는 비율 [0.1, 5.0] 벗어나면 N/A

## 운영 방침

- **옵션 목표가**: 현재가 위 최대 콜 OI Wall = 감마 자석 목표, 해당 만기 = 기한
- **업데이트 시점**: 사용자가 새 옵션 데이터를 요청한 시점에 실행한다. OI/IV/P-C ratio는 시점 의존 데이터이므로 로그의 관측 시각을 함께 표시한다.
- **검증 주기**: 30일 데이터 축적 후 가중치 조정 제안 활성화 (과적합 방지)
- **요청 결과 표시**: 새 스캔 요청이면 흑자/적자 분리, 종목별 "옵션 목표가 + 기한" 포함, 로그 저장
- **중요**: 표시 형식만 바꿀 때(top_n 변경 등)는 재실행하지 말고 로그 JSON에서 읽어서 출력. 재실행은 새 데이터가 필요할 때만.
- **실적일 표기**: 스캐너의 `next_earnings`(yfinance)는 바뀌거나 틀릴 수 있다. 사용자에게 "X일 후 실적"으로 옮기기 전에, 특히 어닝 ±3일 반감이 걸린 종목은 IR 공지나 WebSearch로 날짜를 확인한다(2026-05-05 IONQ 오표기).

## 트래커 — 돌발 호재 분석

`py options_tracker.py --catalyst` 실행 시 전일 점수 vs 실제 수익률 비교 → **분석 실패 vs 돌발 호재** 분류.
돌발 호재로 인한 상승은 옵션 분석 실패로 간주하지 않음 (불가항력).

### 검증 윈도우 (자동 확장)
- 평일 기준 기본 **36시간**
- 비교 두 로그 사이 캘린더 일수 ≥ 2일 (주말·휴장 포함) → **자동 `24×gap + 24h`** 확장
- `--catalyst` 실행 시 반드시 WebSearch로 직접 뉴스 검색 (자동 뉴스필드만 의존 금지)

### 호재 Tier 분류

| Tier | 유형 | 예시 | 처리 |
|---|---|---|---|
| **Tier-1 (명확 호재)** | 구체적 이벤트 | M&A·인수, $30M+ 계약, 정부 계약(DARPA/DOD), FDA 승인, 실적 서프라이즈, 거버넌스 변경 | 돌발 호재 확정 — **분석 실패 제외** |
| **Tier-2 (구조적 호재)** | 섹터 랠리 / 추세 지속 | 섹터 전체 +3%↑, 직전 5D +20% 초과 모멘텀 | 돌발 호재 인정 — **분석 실패 제외** |
| **Tier-3 (약한 시그널)** | 추측·의견 | 애널리스트 목표가 상향, "could/might" 기사, 기술적 분석 | 호재 아님 — **분석 실패로 카운트** |

- **섹터 랠리 기준**: 같은 섹터 종목 3개 이상이 같은 날 +3% 이상 동반 상승 → Tier-2 자동 인정
- **추세 지속 기준**: 옵션 스캔 시점 5D 수익률 +20% 초과 + 점수<40인데 다음 비교일 +3%↑ → 모멘텀 지속, 옵션 분석 한계로 Tier-2 처리
- 섹터/추세 따라가는 영향은 개별 종목 옵션 분석으로 포착 불가 → Tier-2 격상 (사용자 피드백 반영)

## Path-O 필수 실행·출력

1. 어제 로그와 오늘 가격을 매칭한다.
2. 전일 Top 그룹과 Bottom 그룹의 평균 수익률을 각각 계산한다.
3. 예측 방향이 크게 역전된 상위 3개 종목을 각각 WebSearch로 확인한다. 자동 뉴스 필드만으로 결론 내리지 않는다.
4. 각 사례를 Tier-1/2/3으로 분류하고 `분석 실패`, `돌발 재료`, `판단 보류`를 구분한다.
5. 마지막에 적중·실패 요약과 다음 검증 포인트를 제시한다. 돌발 재료 확인 전에는 스코어 가중치 변경을 제안하지 않는다.

새 스캔을 함께 명시적으로 요청한 경우에만 별도 요청 결과로 옵션 순위, 옵션 목표가, 기한을 출력한다. 이 결과를 일일 ETF 보고서에 합치지 않는다.
