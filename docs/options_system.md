## 옵션 스캐너 스코어링 구조 (v3.1)

### 기본 5팩터 (각 20점, 총 100점)
1. **P/C Ratio** — 콜 우위 = 강세
2. **이상 콜 규모** — 달러 기준, 복권성 제외
3. **상대 옵션 강도** — 옵션Vol ÷ 주식AvgVol
4. **IV Skew** — 콜 IV > 풋 IV = 구조적 강세
5. **Term Structure** — 역전 = 단기 이벤트 기대 (값 > 10이면 이상치로 N/A 처리)

### 가감점 레이어

**⑥ 흐름 성격**
| 흐름 | 점수 |
|---|---|
| 강세 방향성 | +10 |
| 이벤트 변동성 | -3 |
| 헤지 + 콜 유입 | -5 |
| 혼조 | -5 |
| 약세 방향성 | -15 |

**⑦ 5일 수익률 (이미 끝난 파티 필터)**
| 구간 | 점수 |
|---|---|
| +30% 이상 | -15 (과열) |
| +20~30% | -8 |
| +10~20% | 중립 |
| +5~10% | +3 (건강한 상승) |
| -5~+5% | +5 (신선한 신호) |
| -10% 이하 | -5 |

**⑧ 섹터 베타**: 같은 섹터 최고점이 40+ 이면 나머지 종목에 +5 (대장주 자신 제외)

**⑨ hot_dollar 누적 신호 (v3.2)**
- 직전 3거래일 로그에서 해당 종목 hot_dollar가 **연속 $40M 이상**이면 +10
- P/C 중립 구간(0.5~1.0)이더라도 대형 포지션이 누적 축적 중인 경우 포착
- 근거: AMD 사례 — 4/17 $149.7M → 4/22 $81.4M → 4/24 $64.2M 3거래일 연속 $40M+ 인데 점수 26~48, 이후 +13.9% 폭등. hot_dollar가 P/C 중립에 의해 상쇄되던 구조적 맹점 보완.

### 구조적 필터
- **OPEX 당일 만기 제외**: 스캔일과 같은 날 만기는 자동 제외 (핀 리스크 방어)
- **소형주 유동성 할인**: 시가총액 < $2B → 최종 점수 × 0.85

## 운영 방침

- **옵션 목표가**: 현재가 위 최대 콜 OI Wall = 감마 자석 목표, 해당 만기 = 기한
- **업데이트 주기**: 매일 재실행 필수 (OI/IV/P-C ratio는 일별 변동)
- **검증 주기**: 30일 데이터 축적 후 가중치 조정 제안 활성화 (과적합 방지)
- **브리핑 표시**: 흑자/적자 분리, 종목별 "옵션 목표가 + 기한" 포함, 로그 저장
- **중요**: 표시 형식만 바꿀 때(top_n 변경 등)는 재실행하지 말고 로그 JSON에서 읽어서 출력. 재실행은 새 데이터가 필요할 때만.

## 트래커 — 돌발 호재 분석

`py options_tracker.py --catalyst` 실행 시 전일 점수 vs 실제 수익률 비교 → **분석 실패 vs 돌발 호재** 분류.
돌발 호재로 인한 상승은 옵션 분석 실패로 간주하지 않음 (불가항력).

### 검증 윈도우 (자동 확장)
- 평일 기준 기본 **36시간**
- OPEX 주말·성금요일·Thanksgiving 등 휴장 포함 시 **자동 96시간** 확장
- `--catalyst` 실행 시 반드시 WebSearch로 직접 뉴스 검색 (자동 뉴스필드만 의존 금지)

### 호재 Tier 분류

| Tier | 유형 | 예시 | 처리 |
|---|---|---|---|
| **Tier-1 (명확 호재)** | 구체적 이벤트 | M&A·인수, $30M+ 계약, 정부 계약(DARPA/DOD), FDA 승인, 실적 서프라이즈 | 돌발 호재 확정 — **분석 실패 제외** |
| **Tier-2 (구조적 호재)** | 섹터 랠리 + 거버넌스 | 섹터 전체 +3%↑, CEO/이사진 교체, 전략적 파트너십 재조명 | 돌발 호재 인정 — **분석 실패 제외** |
| **Tier-3 (약한 시그널)** | 추측·의견 | 애널리스트 목표가 상향, "could/might" 기사, 기술적 분석 | 호재 아님 — **분석 실패로 카운트** |

- **섹터 랠리 기준**: 같은 섹터 종목 3개 이상이 같은 날 +3% 이상 동반 상승 → Tier-2 자동 인정
- 섹터 따라가는 영향은 개별 종목 옵션 분석으로 포착 불가 → Tier-2 격상 (사용자 피드백 반영)

## 브리핑 통합 출력 형식 (Path-B 최종 출력 순서)

아래 순서대로 출력. 섹션 누락 금지.

1. **[흑자기업]** — 정량 지표 + 뉴스 요약
2. **[적자기업]** — 정량 지표 + 뉴스 요약
3. **[뉴스]** — yfinance 수집 뉴스 한글 번역 (정밀 뉴스 요청 시 WebSearch 섹터별 4회 추가)
4. **[옵션 순위]** — 흑자/적자 분리, 종목별 옵션 목표가 + 기한 포함
5. **[어제 복기]** — 장전 시간대만: Top/Bottom 평균 수익률 + 역전 Top 3 돌발 호재 결론
