### 2.2 P9 모멘텀 지속 패턴 (반드시 우선 구현)

**P9 정의 후보** — 17일 회귀로 검증 필요:
- 조건: `flow_type ∈ {강세 방향성, 콜 우위}` + `5D ≥ +10%` + `P/C ∈ [0.10, 0.80]` + `hot_dollar ≥ $0.5M`
- 가설: 소매 FOMO 천장(콘트라리언)과 진짜 모멘텀 지속(추세 추종)은 분리해야 함. 추세 지속은 "P/C 낮음 + 5D 상승"의 **공동 조건**으로 식별
- 검증: JOBY 외에 NVTS·IREN 같은 소형 모멘텀 케이스도 같은 패턴인지 17일치 로그 회귀로 확인

## 3. S&N ①③⑥ sub-score 플래그 (Path-I 후보)

### 3.1 핵심 가설

S&N 총점은 실적 퀄리티를 측정하지만, **단기 주가 반응은 ①(실적강도)·③(미래전망)·⑥(내러티브) 세 항목에 가장 민감하게 반응**한다.

### 3.2 사례

**RMBS Q1 2026 (총점 26/33)**
- ④⑤에서 10점(FCF·SBC 탄탄)으로 총점 채웠으나
- ①③⑥ 합산 12/17점으로 약해 "재무는 좋은데 놀라움이 없다" 구조 → 주가 하락

### 3.3 근거

높은 밸류에이션(PER 30x) 종목은 소폭 비트만으로 기대치를 충족하지 못함. GAAP 영업이익 YoY 감소, R&D 비용 급증 등이 기관 투자자에게 부정적 신호로 작용.

### 3.4 Path-I 진입 조건

- **현재 검증 케이스 3건**: UNH, INTC, RMBS
- **개선 제안 활성화 기준**: 5건 누적 시
- **개선 후보**: "①③⑥ sub-score 합산"을 별도 지표로 추가하는 방안 검토
- 5건 미만이므로 개선 제안 비활성화 구간 — 5건 도달 후 Path-I에서 자동 트리거
