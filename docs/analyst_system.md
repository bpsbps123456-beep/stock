# 애널리스트 신호 추적 시스템 (Path-A)

> 활성 기준일: **2026-07-18**
> Path-A(애널리스트 업데이트·성적표)의 수집·기록·채점·행동 규칙 정본이다.

## 1. 목적과 범위

- 두 펀드(AI·반도체 테마)의 섹터 쏠림 리스크를 보완하기 위해, 시장 국면·섹터 순환·가격 구조 전환을 외부 신호원 3인으로 교차 확인한다.
- 이 시스템은 매매 신호 생성기가 아니다. 3인의 의견은 아래 행동 규칙 매트릭스를 통해서만 반영하며, 객관 가격·수급 데이터가 항상 3인 의견보다 우선한다.
- 수집은 WebSearch만 사용한다(사용자 결정 2026-07-18). 유료 원문의 세부 가격 레벨이 유실될 수 있음을 감수하고, 확보 못한 값은 가정으로 채우지 않고 `null`로 남긴다.

## 3. 수집 규칙 (업데이트 모드)

트리거: "3명 업데이트" / "오늘 3명 업데이트" / "애널리스트 업데이트"

1. WebSearch 3회 이상: ① `Reuters Mapping the Market` ② `Mike Wilson Thoughts on the Market` ③ `Eugenio Catone Seeking Alpha`. 오늘 → 어제 → 이번 주 순으로 확인한다.
2. 신규 발언이 없으면 "신규 없음"으로 종결한다. 억지로 오래된 글을 신규로 취급하지 않는다.
3. 신규 콜은 즉시 `data/analyst_log/`에 기록한다(스키마 §4). 읽고 기록하지 않는 것을 금지한다 — 기록 없는 콜은 성적표에 들어가지 못하고 선택 편향을 만든다.
4. 출력 표: 인물 | 발표일 | 대상 | 방향 | 이전 전망 대비 변화 | 행동 조건 | 무효화 조건.
5. `py analyst_tracker.py verify`를 실행해 대기 중인 과거 콜 채점을 갱신한다.

## 4. 콜 기록 스키마

파일: `data/analyst_log/YYYY-MM-DD_<analyst>_<target>.json` (콜 1건 = 파일 1개, 날짜가 월 단위면 `YYYY-MM`)

| 필드 | 내용 |
|---|---|
| `analyst` | `gabriel` / `wilson` / `catone` |
| `published` | 최초 공개일 `YYYY-MM-DD` (월만 알면 `YYYY-MM`) |
| `date_precision` | `day` / `month`. **`day`만 채점 대상** — 날짜를 가정으로 채우지 않는다 |
| `target` | 채점용 티커 (`^GSPC`, `^SOX`, `^IXIC`, `RSP` 등) |
| `direction` | `bullish` / `bearish` / `neutral` |
| `relative` | `true`면 대상의 절대 수익이 아니라 `^GSPC` 대비 초과수익으로 적중 판정 (예: 윌슨의 시장 폭 확산 콜 → RSP) |
| `horizon` | 며칠 / 몇 주 / 몇 달 |
| `thesis` | 핵심 논리 1~2문장 |
| `action_condition` | 어떤 가격에서 매수·축소인지 (없으면 `null`) |
| `levels` | 제시된 지지·저항·이평선 수치 (없으면 `null`) |
| `invalidation` | 어떤 조건에서 전망이 틀리는지 (없으면 `null` — 무효화 조건 없는 콜은 그 자체로 감점 요소) |
| `scoreable` | 가격 채점 가능 여부. 장기 시나리오·정성 논평은 `false` |
| `source` | `websearch` / `user_provided_summary`(백필) |
| `verification` | 채점 결과. `analyst_tracker.py`가 자동 기입 (§5) |

## 5. 채점 규칙

`py analyst_tracker.py verify`가 `scoreable: true`이고 `date_precision: day`인 콜을 자동 채점한다.

- 진입가: 발표일 종가 (발표일이 휴장일이면 다음 거래일 종가).
- **5거래일 / 20거래일**: close-to-close 수익률과 `^GSPC` 대비 초과수익. 대상이 `^GSPC` 자체면 절대 수익만.
- **MFE / MAE**: 20거래일 창 안의 종가 기준 최대 유리·불리 움직임 (콜 방향 기준 — 약세 콜은 하락이 유리).
- **놓친 상승 비용**: 약세 콜 한정. 진입가에서 창 내 최고 종가까지의 상승률. 이 지표가 상습 약세론자를 걸러내는 최우선 지표다.
- 적중 판정: `relative: true`면 20거래일 초과수익 부호, 아니면 20거래일 대상 수익률 부호가 `direction`과 일치하는지로 판정한다.
- 데이터가 아직 없으면 `null` + `status: pending/partial`로 남기고, 이후 `verify` 재실행 시 채워진다.
- 2026-07-18 백필 18건은 결과를 이미 아는 상태에서 소급 기록한 것이므로 `source: user_provided_summary`로 표시하며, 성적표에서 "참고 베이스라인"으로 구분한다. 검증된 승률로 취급하지 않는다.

## 6. 행동 규칙 매트릭스

| # | 신호 상황 | 행동 |
|---|---|---|
| 1 | 윌슨 단독 약세 전환 | 매도 금지. 시장 국면 경계 신호로만 기록 |
| 2 | 카토네 단독 폭락·조정 전망 | 매도 금지. 반대 논리를 체크리스트에 추가만 |
| 3 | 테런스가 구체적 지지선 제시 + 실제 **주간 종가** 이탈 확정 | 해당 자산 비중 축소 |
| 4 | 테런스 가격 신호 + 윌슨 섹터 순환 판단 일치 | 가장 강하게 반영 (예: 반도체 축소 + 상대강도 개선 섹터로 이동) |
| 5 | 3인 의견과 객관 가격·수급 데이터 충돌 | 객관 데이터 우선 |
| 6 | 카토네가 같은 약세 논리를 3개월 이상 반복 | 성적표 근거로 가중치 강등·제외 검토 |
| 7 | 테런스 무효화 레벨 회복·유지 | 해당 약세 대응 해제 |

## 7. 성적표 모드

트리거: "애널리스트 성적표" → `py analyst_tracker.py scorecard`

- 인물별: 콜 수, 채점 수, 방향 적중률, 5d/20d 평균 (초과)수익, 약세 콜 평균 놓친 상승 비용.
- 백필(`user_provided_summary`)과 실시간 수집(`websearch`) 콜을 분리 집계한다.
- 카토네의 관찰→핵심 승격 또는 제외, 로스터 변경 제안은 실시간 수집 콜 채점이 인물당 5건 이상 쌓인 뒤에만 한다 (Path-I와 동일한 5건 원칙).
