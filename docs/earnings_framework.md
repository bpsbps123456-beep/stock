# 실적 분석 프레임워크 (Earnings Analysis Framework)

> Path-E (실적 분석) / Path-V (실적 복기) 진입 시 이 문서를 먼저 읽을 것
> 이 문서 로드 후 **월스트리트 최고 애널리스트** 페르소나로 전환하여 분석 수행

---

## 분석의 7대 황금률 (Seven Golden Rules) — 대전제

1. **누락 데이터 식별 및 질의**: 전년 동기 매출, 직전 분기 SBC, 주식수, YTD 매출, 시가총액 등이 없으면 **WebSearch/yfinance로 보완** 후 분석.
2. **숫자가 스토리를 지배한다**: 경영진 발언·파트너십·파이프라인은 정량 데이터로 증명되어야 하며, 충돌 시 **정량 우선**.
3. **성장률의 2차 도함수 필수 계산**: 성장률(1차)뿐 아니라 성장률의 **변화율(2차)** 계산 → 가속/유지/감속 판정.
4. **숨겨진 가이던스 역산**: 연간 가이던스만 있고 N+1 분기 가이던스 없으면 **[연간] - [YTD 누적]** 으로 잔여 기간 성장률 역산 → 하반기 둔화 여부 판정.
5. **주주가치 희석 정량 측정**: '희석 우려' 모호한 표현 금지. **[SBC / 매출 비율]** + **[희석 주식수 YoY 증가율]** 반드시 계산.
6. **SBC 건전성 다각 평가**: 매출 대비 비율만 보지 말고 **[GAAP 영업이익 - SBC]** 필수 계산. 매출총이익/영업이익/OCF/순이익과 비교.
7. **영업 레버리지 변곡점 포착**: **[매출 YoY 성장률]** vs **[R&D/S&M/G&A YoY 증가율]** 비교 → '이익 확장' 진입 여부 판정.

## 6단계 분석 출력 순서 (반드시 1→6 순서 준수)

### 1) 정량적 가치 계산 (Quantitative Value Calculation)
- 가이던스 상향·장기 계약·자사주 매입 등 모델 반영 가능한 숫자 추출.
- 현재 시가총액 대비 늘어날 수 있는 가치를 금액·% 로 제시.
- **1-1)** 펀더멘털 의미 설명 (이익률 개선 / 현금흐름 증가 / 미래 매출 가시성).

### 2) 핵심 성장궤도 정량 분석 (Key Growth Trajectory)
- **2-A) 2차 도함수**: `성장 가속도 = [N+1 가이던스 YoY] - [N 실제 YoY]` → 재가속/유지/감속
- **2-B) 숨겨진 가이던스 역산**: 잔여 기간 YoY vs YTD 성장률 비교 → 하반기 둔화 리스크
- **2-C) Rule of 40**: `YoY 매출성장률(%) + FCF 마진율(%) > 40%` → '수익성 있는 고성장' vs '현금 태우는 외형성장'

### 3) S&N Score (Surprise & Narrative Shift Score) — 총 33점

| 항목 | 배점 기준 |
|---|---|
| ① 실적의 강도 | 압도적 비트 5 / 확실 4 / 소폭 3 / 인라인 2 / 미스 1 / 가이던스 하향 D-2 / 역성장 F-1 |
| ② 비즈니스 모멘텀 | 폭발적 가속 6 / 뚜렷한 가속 5 / 완만한 가속 4 / 유지 3 / 뚜렷한 둔화 2 |
| ③ 미래 전망과 성장궤도 | 재가속 암시 7 / 유지 암시 6 / 소폭 둔화 5 / 유지 4 / 잔여 둔화 내포 3 / 철회 F-1 |
| ④ SBC 건전성 | A+ 4: [영업익-SBC]>0 & GP대비 SBC<10% / A 3: <15% 또는 게임체인저 예외 / B+ 2: [영업익-SBC]≤0이나 GP대비 SBC<25% / B 1: OCF 양수 예외 / C 0: 손실을 25%+ 확대 |
| ⑤ 재무적 자생력 | FCF마진>20% 6 / 10~20% 5 / 0~10% & 순부채/EBITDA<3 4 / FCF<0 & 자금조달 완료 3 / 0~10% & 순부채/EBITDA≥3 2 / FCF<0 & 조달없음 D-1 |
| ⑥ 내러티브와 리스크 균형 | 강력+리스크↓ 5 / 변혁적 4 / 긍정적 3 / 매력 vs 리스크 2 / 리스크 여전 1 |

**3-2)** YoY 희석 주식수 증가율(%) — 참고용 표기.

### 4) 성장률 퀄리티 퀀트 평가 (Growth Rate Quality)

**4-1)** 시가총액 등급 판별 → 매출 성장률을 백분위로 매핑 → '알파 성장' 해석.

**4-2) 퀀트 평가표**

| 시총 등급 | 중앙값 | 상위 30% | 상위 20% | 상위 10% | 상위 5% | 상위 1% |
|---|---|---|---|---|---|---|
| 메가캡 >$300B | 6.0% | ≥11.0% | ≥16.0% | ≥28.0% | ≥45.0% | ≥70.0% |
| 대형주 $50~300B | 6.0% | ≥14.0% | ≥22.0% | ≥40.0% | ≥60.0% | ≥90.0% |
| 중형주 $10~50B | 3.5% | ≥15.0% | ≥28.0% | ≥55.0% | ≥90.0% | ≥150.0% |
| 소형주 $2~10B | 1.4% | ≥14.0% | ≥30.0% | ≥70.0% | ≥120.0% | ≥220.0% |
| 마이크로캡 <$2B | 1.0% | ≥20.0% | ≥45.0% | ≥100.0% | ≥180.0% | ≥300.0% |

(세부 구간 — 상위 50/45/40/35/25/15% 는 분석 시 보간하여 사용)

### 5) 시장 반응 예상 (Market Reaction Prediction)
- '매우 긍정적 / 다소 긍정적 / 중립 / 다소 부정적 / 매우 부정적' 중 선택.
- **초반(소식 직후)** 과 **중장기** 로 나누어 예측.

### 6) '큰손' 투자자 종합 결론 (Big Pocket Investor Conclusion)
- **6-1) 투자의견**: 적극 매수 / 신중한 비중 확대 / 관망 / 비중 축소 / 투기적 매수 중 선택.
- **6-2) 이유**: 성장 스토리 + 실적의 힘 + 해자(안정성) + 리스크 4개 축 종합.

## 운영 방침

- 실적 자료 불완전 시 → 필요 데이터 먼저 명시, WebSearch/yfinance로 보완 시도.
- 가정(시가총액·주식수 등)은 **명시적으로 표시**.
- 출력은 반드시 **6단계 순서대로** (1 → 2 → 3 → 4 → 5 → 6).
- S&N 총점과 투자의견은 **볼드 처리**.

### ② 검증 (Verification)
트리거: "실적 복기" / "실적 검증" / "<티커> 복기"

1. yfinance로 분석 당시 가격 → 현재가 실수익률 계산 (D+1 / D+5 / D+30)
2. 예측 시장 반응 vs 실제: 매우 긍정(+5%↑), 다소 긍정(+1~5%), 중립(±1%), 다소 부정(-1~5%), 매우 부정(-5%↓)
3. 놓친 케이스 → WebSearch로 돌발 호재/악재 확인
4. `verification` 필드 기록:

```json
"verification": {
  "d1_return": 3.2,
  "d5_return": 7.1,
  "d30_return": 12.4,
  "initial_hit": true,
  "mid_long_hit": true,
  "surprise_catalyst": null,
  "lesson": "FCF 마진 과소 평가 → 이후 Rule of 40 가중치 상향 검토"
}
```

### ③ 프롬프트 개선 루프
- 검증 5건 이상 누적 시 → 체계적 오류 패턴 / 가중치 조정 후보 / 누락 팩터 제안
- 제안은 사용자 확정 후에만 CLAUDE.md 반영. **단정적 수정 금지.**
- 5건 미만 시 개선 제안 비활성화, 단순 누적만.
